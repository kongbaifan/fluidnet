# 使用指南 · v0.2

## 元件、端口和画布

左侧模块库支持点击添加、拖入画布和名称搜索。点击元件后，在右侧编辑参数与介质归属。数值在失去焦点或按 Enter 后提交；性能曲线修改后点击“应用曲线”。

拖动端口可建立连接，通路的实际流向由求解结果决定。点击连线后，可以用删除按钮或 Delete 键单独移除连接，元件会保留；Ctrl+Z 可恢复。模型参数中的高差、泵扬程和有向流量按元件定义的参考方向解释。需要一分多或多合一时使用连接节点。所有画布上的元件共同参与同一个项目的计算。

用鼠标左键框选，或按住 `Ctrl` 单击多个元件；鼠标中键或右键拖动画布，滚轮缩放。工具栏支持撤销、重做、复制、删除和适应画布。快捷键：`Ctrl+S` 保存、`Ctrl+Z` 撤销、`Ctrl+Y` / `Ctrl+Shift+Z` 重做、`Ctrl+C` / `Ctrl+V` 复制粘贴、`Delete` 删除选中的元件或连接。

## 参数和单位

内部计算和 JSON/CSV 结果采用 SI 单位：压力 Pa（绝压）、温度 K、质量流量 kg/s、长度 m、热功率 W。显示设置可切换 kPa 表压/绝压、m³/h / kg/s 和 °C / K。录入时以输入框右侧显示的单位为准。

默认大气压力是 `101325 Pa`，因此 `0 kPa(g)` 对应 `101325 Pa` 绝压。绝压不能为零。水的温度和压力必须处于 IF97 物性范围内，并高于相应饱和压力；不满足时会停止求解并指出原因。

## 模型检查和计算

先点击“检查模型”。每个液压连通部分需要有效的压力参考，必需端口应完成连接，几何和性能参数必须满足各元件要求。诊断列表会给出原因，点击可选中相关元件。

“稳态求解”计算当前工况下的网络状态。水箱在稳态中使用当前液位，若存在净流入或净流出，应切换动态运行查看液位变化。

“动态运行”按指定步长更新设备和控制状态，每步重新求解网络。运行中可暂停、继续或停止；暂停后可单步推进。重置会以本次工况的初始条件创建新的暂停运行记录。

修改影响物理模型的参数后，旧结果会标为过期，需要重新计算。保存项目和保存运行记录是独立的：计算会保留当次模型快照和结果，编辑后的项目需点击“保存项目”。

## 曲线与导出

计算完成后选择元件，切到右侧“运行结果”，勾选需要记录的变量。所选变量将在下一次运行中记录，最多 64 条。下方面板可查看曲线、诊断和结果总表。

- JSON：运行信息、模型快照和最后一帧结果。
- CSV：时间序列，列名保留变量路径，数值采用 SI 单位。
- HTML：可在浏览器打开的计算报告。

运行历史会保存于本地工作区，可重新查看已有运行。历史结果对应当时的模型和参数，不会因后来修改项目而改变。

## 工况与介质

工况用于保存元件参数覆盖值，可以切换计算或批量对比。设计工况、阀门节流和泵速变化可先从并联管网示例体验。

介质配置在项目中单独管理，换热器的两侧介质通路保持独立。组合的复制、插入和版本应用会保留成员的介质归属；同名 ID 对应不同配置时会生成新的 ID，避免覆盖目标项目的介质。

## 封装组合和编辑内部结构

1. 在同一画布上框选元件，或用 `Ctrl+单击` 多选，点击工具栏“封装选中元件”。一个元件也可封装成组合。
2. 填写组合名称。未在内部连接的流体端口会列入对外接口，可选择需要从组合属性面板调节的参数。
3. 点击“封装为组合设备”。主画布将显示一个组合外壳；拖动、复制或删除它时，内部成员一起处理。撤销可恢复。
4. 双击外壳或点击“进入内部”，查看真实元件和内部连线。添加的元件自动成为该组合的成员；重新连接内部端口时，已成为内部通路的对外接口会移除。
5. 编辑完成后从顶部“主画布”返回，继续连接组合和其他设备。计算始终使用所有真实元件，展开、折叠与封装本身不改变物理计算结果。

“在主画布展开成员”只切换显示方式；“解散组合并保留元件”移除组合关系，保留元件和连接。首版只支持单层组合：同一个元件只能属于一个组合，组合内部不能插入或粘贴另一组合。需要重组时先解散原组合。

## 配置端口与参数接口

在组合属性或内部画布顶部点击“配置接口”。每个接口拥有稳定 ID、显示名称和一个真实内部目标。ID 用于版本间匹配，显示名称可修改；同一内部端口或参数只能暴露一次。参数的单位、范围和运行时可调能力沿用原元件定义。

已经接到外部管路的端口不能直接取消暴露；需要修改外部连接时先返回主画布处理。必需端口应在内部完成连接或暴露给外部。内部正在搭建时可先保存项目，再通过“检查模型”定位尚未接好的端口。封装或发布型号时会检查接口完整性；组合中的控制器应连同它控制和测量的设备一起封装。

选中组合后，右侧“对外参数”直接编辑内部元件的对应值。选择工况时写入工况覆盖值，运行时带绿点的参数仍可在线调节。“内部元件与结果”可跳转到具体元件查看结果与设置曲线记录。

## 型号库、版本与手动应用

单个元件可保存为设备参数型号；组合可通过“保存到型号库”发布其内部结构、接口和介质配置。左下角“型号管理与验证”提供搜索、插入、编辑、导入、导出和归档。附带的三套型号如下：

| 型号 | 内容与用途 |
| --- | --- |
| 泵阀组合 | 循环泵、调节阀和出水管，两个对外端口，观察泵扬程与管流量 |
| 双侧换热机组 | 热侧管道、冷侧管道和换热器，两侧水配置与温度独立 |
| 水箱调节单元 | 两个水箱、联通阀和管道，依靠内部边界验证液位、存量和慢动态 |

编辑窗口中的“保存型号”创建 v1，“保存新版本”保留旧版本并追加新记录。项目里的每个实例保存自己的完整定义，保存型号不会自动改变实例。编辑内部结构可用“插入副本并编辑内部结构”，完成后从该组合重新保存到型号库。

要更新实例，先选中它，在库中点击“应用到选中实例”，或在编辑窗口选择历史版本后点击“应用此版本到选中实例”。预览列出成员、内部连接、接口映射与名称、基础参数的变化；点击“应用此版本”后才写入当前项目，并可撤销。有效的工况覆盖、曲线和控制引用会保留。如果版本会移除已有外连接口，或使工况、曲线、控制引用失效，应用会被拒绝，先处理提示的引用再试。

型号编辑后需先保存才能应用。保存新版本应基于库中最新版本；其他窗口已更新时会提示冲突，可重新加载，或“另存为新型号”。旧版本可直接用于项目实例的显式回退。

“导出”生成 `.fluidnet-template.json`；“导入型号 JSON”校验后创建独立的新型号，不覆盖原库条目。归档后型号从常规列表隐藏，已有实例仍可使用。勾选“显示已归档”可查看历史或导出。旧型号定义无效时会显示原因，可导出修正后重新导入。

## 独立验证台

在型号编辑窗口切到“独立验证”。有对外端口的型号可以为每个接口配置测试边界，输入单位固定为 **绝对压力 kPa、温度 °C**。无对外端口的完整回路（如水箱调节单元）使用内部边界。

选择“稳态验证”或“慢动态验证”，点击“开始验证”。动态验证支持暂停、继续、单步和停止；首次“验证单步”初始化到 `0 s`，再次点击前进一个步长。结果区显示残差、曲线和内部元件结果。定义变化后会提示重新验证。

验证会创建独立的项目快照和运行记录，测试边界只存在于验证副本中，不会加入正在编辑的项目或正式型号。关闭编辑窗口会停止该窗口尚未结束的验证任务。保存型号时会一并保存测试边界配置，方便下次复查。

## 项目和备份

每次成功保存都会增加项目版本。撤销/重做改变模型内容，并保留当前保存版本的标识；需要再次保存才能持久化这些修改。另一个窗口保存同一项目时，系统会提示版本冲突，此时可重新载入或另存为副本。

浏览器自动保留未保存草稿，重新打开同一项目时可选择恢复。跨电脑迁移单个项目可使用项目工作区中的 JSON 导出和导入；迁移全部项目、历史曲线及设备型号时，应在停止服务后复制完整的 `workspace` 文件夹。

v0.2 使用项目格式 `schema_version: 2`，可以读取有效的 v0.1 项目和旧浏览器草稿。旧分组初次打开保持展开，原位置保持不变。首次打开旧数据库会生成 `workspace/backups/studio-before-v2-*.sqlite3`，随后升级型号版本表；历史项目与运行快照保持原存档。升级前请保存草稿、停止旧服务并保留完整工作区副本；两个版本不要同时访问同一数据目录。

## 适用边界

当前求解模型为单相液态水的准不可压缩网络和设备慢动态，适用于本版本元件支持的水系统。动态步长应根据设备和控制时间尺度选择，缩小步长并比较结果可用于评估离散误差。此版本没有水锤、两相流或相变模型；其他介质类别仅保留配置与扩展入口。自定义设备使用已有元件、性能曲线和参数配置，不执行用户算法代码。1000 元件和 64 条曲线是结构上限，大规模性能仍需单独验证。
