# FluidNet Studio 全页面交互原型

入口：[`../fluidnet-studio-prototype.html`](../fluidnet-studio-prototype.html)。可直接用 Edge / Chrome 打开，页面和图标均已打包，不依赖外部资源。

这是对照倍思鹿教程完成的下一轮界面设计，重点区分模块定义、设备型号和项目实例，并串起编辑、应用与观察结果的流程。

## 页面清单

| 页面 | 已设计的内容与交互 |
| --- | --- |
| 首页 | 最近项目、消息，以及“打开示例调参”和“进入模块开发”两条体验路径 |
| 项目管理 | 新建、复制、列表/卡片、搜索、示例与 JSON 导入 |
| 项目建模 | 可收起模块库、大画布、多画布、放置与拖放、连线检查、设备快捷栏与右键操作、旋转/撤销/重做、通路提示、可停靠参数窗和同屏曲线 |
| 模块库 | 卡片/紧凑列表、分类与自建分组、搜索、新建模块、编辑定义与插入项目 |
| 模块开发 | 绘制模块、变量属性、变量值、设备型号、代码、通路设置，共 6 个页签；代码页同时编辑运行代码、Header 和设计函数 |
| 节点定义 | 流体、信息、电力、机械接口，变量含义、单位与连接规则 |
| 型号库 | 从模块库值或设备当前值/草稿/库值命名保存、参数与自定义变量、版本记录、归档、插入、应用到已有设备 |
| 曲线 | 当前/历史来源、系列开关、基准对照、游标与固定读数、变量曲线、CSV 导出 |
| 运行记录 | 独立快照、来源、运行状态、参数、曲线和 JSON 导出 |
| 控制逻辑 | 控制名称、周期、读写目标、Lua 文本与调用顺序预览 |
| 设置 | 项目/画布、介质和单位约定、求解配置、显示、保存与交换 |
| 使用指南 | 12 页导航、完整体验路径、三类对象、快捷键 |

项目设备窗口默认显示常用参数，提供“全部变量”、型号、结果、连接和模块定义入口。窗口支持多开、移动、缩放、置顶、收起及恢复；主要操作在常见笔记本尺寸下保持可见。

### 模块库紧凑列表

模块库搜索栏旁可切换“卡片视图”和“紧凑列表”。列表在桌面每行显示模块名称、标识、版本、分组、端口/通路/变量数量及编辑、插入操作；窄屏调整为两行。切换保留当前搜索和分组，视图偏好会自动记忆，刷新后继续使用。

### 模块分类与自建分组

进入“模块”，点击左侧“模块分类”旁的“新增分组”。分组可以先留空；点击右上角“保存原型”后，空分组和模块归类会在刷新后恢复，也随完整原型 JSON 和型号库 JSON 交换保留。

- 选中分组后点击“新建模块”，默认使用当前分组；创建弹窗中也可选择其他分组。
- 点击模块卡片上的分组标签，可将已有模块移到其他分组。建模画布的模块库同步显示新的归类。
- 自建分组支持重命名，组内模块同步更新分类，型号和项目设备仍引用原来的模块。空分组可删除；有模块时先移动模块，再删除分组。
- 内置分类保留原名称。自建名称最多 32 个字符，不能重名或留空，最多 64 个自建分组。旧存档从模块的分类字段补齐分组。

### 同屏建模与调参

首页点击“打开示例调参”，进入泵阀并联管网，并打开阀门参数和底部曲线。在宽度至少 1000 px 的窗口中，参数停靠到右侧，画布为它保留空间；较窄窗口使用原有浮窗。入口会沿用已存在的泵阀示例及其编辑内容。

- 模块库开关在桌面和窄屏都可收起、展开。桌面收起后释放画布宽度；窄屏以抽屉展示，库内也有关闭按钮。
- 设备窗口标题栏可切换停靠与浮动，每次最多停靠一台设备；多设备浮窗继续保留。停靠偏好随“保存原型”保留，关闭窗口不会停止项目运行。
- 点击画布右侧“曲线”，展开或收起底部观察区。可查看主管与 A/B 支路流量、出口压力、出口温度，以及已加入当前项目的观察变量；完整曲线页保留历史记录与大图分析。
- 曲线上的竖向虚线标记参数应用时刻，底部显示最近一次参数变化。点击曲线固定读数，运行和窗口尺寸变化时保留对应仿真时间；“恢复实时读数”解除固定。
- “保存草稿”和“参数生效”分别显示。应用参数后，已有结果提示“等待重新采样”；运行或单步后结果更新。旧存档无法确认结果对应参数时，提示先单步核对。
- “适应画布”按设备实际分布调整视野，缩放以视野中心为基准；模块库和曲线开关、观察变量随浏览器布局偏好保留。

### 画布直接操作

单击设备后，画布上方出现设备快捷栏；右键设备可打开同一组操作。可以直接查看参数、全部变量、选择型号、顺逆时针旋转以及进入模块定义。选中设备后按 `R` 顺时针旋转 90°，`Shift+R` 逆时针旋转；连线跟随端口更新，支持撤销/重做，输入文字时不会触发旋转。

悬停设备显示已启用的内部通路，悬停或键盘聚焦端口时只突出关联通路，并提示端口名称、类型和连接设备。双侧换热器的两条通路分别显示。从设备进入模块定义或变量定义后，可点击“返回 V1 设备”等按钮回到原画布和设备草稿。选择型号仍先进入草稿，再预览并应用。

### 设备实例的全部变量

在“建模”中双击设备，选择“全部变量”。窗口自动加宽，可用标题栏按钮最大化；变量标识、中文名称、单位分别显示在独立列中，每个变量占一行。表头和变量标识列固定，支持搜索、分组、仅可写差异和三组库值对照。

- 默认编辑“待应用草稿”，与“参数与型号”页的常用参数双向同步。点击底部“预览并应用”核对变化后生效；保存只保留草稿。
- 每台设备各有三组库值，初次载入时复制模块的方案，库值 1 的参数以当前实例为准。之后的编辑、存入和应用不会改变其他设备或模块测试值。
- 在“编辑”中选择库值，修改参数或自定义变量；“应用库值”先预览，再整组校验并应用。选择“当前值存入此库”会保存已生效值及已有结果，不包含待应用草稿。
- 参数和自定义标量 / 数组可编辑。端口结果、项目步长、运行状态与项目工质只读。现有演示仅采样部分设备出口的流量、压力和温度；未采样项显示“—”，双侧换热器不复用单出口数据。
- 运行时只刷新当前值，保留输入焦点、草稿与表格滚动位置。设备库值和自定义变量随保存、复制、撤销及完整原型 JSON 交换保留；旧原型数据载入时补齐实例数据。

### 变量观察与保存型号

常用参数名称旁的表格按钮可定位到对应变量。“全部变量”每行末尾提供“同屏观察”和“查看变量定义”：观察按钮把变量加入建模页底部曲线，定义按钮定位到模块变量并提供返回设备入口。

- 曲线采样参数、自定义标量及支持的系统标量，始终记录已生效值；草稿和库值在确认应用前不会影响曲线。重复观察同一变量不会新增重复曲线，变量改名后仍按稳定标识读取采样。
- 端口曲线仅提供现有演示可采样的单流体出口流量、压力和温度；数组及其他端口的观察按钮显示禁用原因。压力与变量表统一为 MPa，旧出口采样按原 kPa 值换算；参数仍使用自身定义的单位。自定义变量不会借用同名出口的旧记录。
- 宽屏观察时自动停靠设备窗口，中文名称和单位置于标识下方，让当前值、草稿和操作同时可见；三组对照仍可横向滚动。窄屏自动收起窗口，露出曲线与运行按钮，还原后保留搜索和未应用编辑。
- 在参数页或全部变量页点击“保存为型号”，可选择当前已生效值、待应用草稿或任一组库值，预览后命名保存。型号包含可写参数和自定义变量；不包含端口结果及系统设置。保存型号不会自动应用草稿。
- 型号详情显示来源和自定义变量，应用到另一台同模块设备时先进入该设备草稿。校验不通过时整组拒绝保存或应用，其他设备保持各自的已生效值。

### 合并的代码页

在“模块开发”中进入“代码”，左侧为运行代码，右上为 Header 公共声明，右下为设计函数；窄屏按顺序上下排列。三组设计函数通过下拉选择，各自独立保存。切换函数保留其他编辑区的光标、选区和滚动位置。

每个区域可单独检查括号结构，顶部“检查与编译预览”会检查运行代码、Header 及全部三组设计函数。选择变量后可插入到指定编辑区的光标或选区；点击编辑区会同步插入位置。编辑支持 Tab 缩进和同步行号。

“保存定义”或 Ctrl+S 一并保存所有代码，完整原型 JSON 也包含这些文本。此前停在“Header”或“设计函数”页的保存记录会自动进入合并后的代码页。编译和设计函数调用仍是流程预览。

## 建议体验路径

首次使用可直接点击首页“打开示例调参”：单步一次，将 V1 开度从 80% 改到 65%，保存草稿后确认它仍未生效，再预览并应用、单步，观察两条支路的流量及参数应用标记。最后保存原型并刷新，重新打开 V1 检查恢复。

自定义模块的完整体验路径：

1. 首页点击“进入模块开发”，检查调节阀的入口、出口与内部通路。
2. 在“变量属性”配置常用变量与快捷控件；在“变量值”选择库值 2，将开度设为 65%。
3. 预览并应用库值到模块当前值，保存为命名型号。
4. 在型号库中选择“应用到已有设备”，选择泵阀并联管网的 V1。
5. 在设备窗口中先保存草稿，查看待应用项，再预览差异并确认应用。
6. 主系统运行或单步，从设备结果中将流量加入曲线，保存运行记录。
7. 保存原型并刷新，或导出 JSON 后重新导入，检查项目、型号和参数恢复。

## 状态与数据规则

- “保存”记录整个原型草稿；“应用”改变目标设备或模块测试初值。两个动作独立。
- 三组库值分别保留。无效参数、工质数组或比例会阻止整组应用。
- 型号版本更新不自动修改项目实例；同一型号的新版本也须显式应用。
- 端口标识稳定，重命名同步变量；已被通路或项目连接引用的端口不能直接删除。
- 内部通路检查端口存在性、输入输出方向、领域一致性及重复绑定。
- 项目运行期间，关闭窗口和切换页面不结束任务。刷新恢复时运行中的任务变为暂停。
- 记录保存当时的参数和曲线快照。变量曲线保留项目来源和单位。
- 当前浏览器的本地记录与 JSON 交换文件属于这份原型；旧大画布原型使用独立入口和记录。

## 演示范围

运行响应、工况曲线和编译流程使用示例数据。代码可以编辑、保存和检查括号结构，没有执行 C/C++ 或 Lua，也没有调用求解器、REFPROP、外部接口或硬件。

当前原型已移除独立验证台和数据对接页面及相关快捷入口，共 12 个主页面。旧版对应地址会回到首页；原有保存文件继续兼容，旧单机任务保持暂停，不计入当前运行任务。

本轮保留纯液态水作为实际产品的目标场景，其余端口与工质用于定义页面演示。原型限制为每画布 64 个设备、每项目 8 张画布、64 个模块、每模块 24 个端口 / 160 个变量，以及最近 30 份记录、每次运行最近 1200 个采样点。这些是原型容量，不是正式计算能力上限。

## 构建与检查

在仓库根目录执行：

```powershell
node output/visualizations/studio/build.mjs
node output/visualizations/studio/preview.mjs
```

预览服务只绑定本机 `127.0.0.1`，默认端口 8789；端口占用时会选择 8790–8799。关闭服务后仍可直接打开单文件原型。

源码由 `index.html`、三份样式文件及 `data.js`、`app.js`、`instance-variables.js`、`workbench.js`、`module-groups.js`、`canvas-actions.js`、`variable-flow.js` 和 `runtime.js` 组成。`instance-variables.js` 管理设备变量、实例库值与表格交互；`workbench.js` / `workbench.css` 管理工作区布局、结果状态及同屏曲线；`module-groups.js` 管理分类和列表；`canvas-actions.js` 管理设备直接操作及通路提示；`variable-flow.js` 管理变量采样、观察与设备保存型号；`interaction-details.css` 配套本轮交互样式，基础样式位于 `styles.css`。`build.mjs` 将本地 Lucide 图标和源码打包成单文件页面。正式 `web/src` 与后端没有参与此原型构建。

浏览器检查：

```powershell
node output/visualizations/studio/tests/pages.mjs
node output/visualizations/studio/tests/workflow.mjs
node output/visualizations/studio/tests/details.mjs
node output/visualizations/studio/tests/instance-variables.mjs
```

检查使用隔离的 Edge 浏览器上下文，结果与截图写入 `.cache/studio-prototype-qa/`。覆盖 12 个页面、6 个模块页签和 5 个设置页面；在 1366×768、1600×1000、1024、736、320 px 宽度检查布局，并验证库值/型号/实例流程、项目任务状态、曲线、窗口、多画布和 JSON 恢复。检查也覆盖已移除页面的旧地址恢复与旧单机任务暂停。代码页另检查三个编辑区、三组设计函数、变量插入方向、光标与滚动、统一保存及旧页签恢复。

工作区专项检查覆盖桌面模块库释放空间、停靠与画布不重叠、保存与应用分离、结果时效、参数事件标记、运行中的固定读数与编辑焦点、布局恢复，以及窄屏和深色显示。

分组专项检查覆盖新增与取消、名称校验、空分组保存恢复、新模块默认分组、已有模块移动、重命名与引用保持、空分组删除、JSON 交换、旧存档兼容，以及 1366 / 1024 / 736 / 320 px 和深色显示。

交互专项检查覆盖紧凑列表切换与记忆、画布旋转与连线、型号草稿与取消、内部通路隔离、变量定位与返回、已生效值采样和压力单位、自定义变量保存型号并应用到另一台设备、JSON 与旧采样兼容，以及窄屏观察/还原和深色显示。
