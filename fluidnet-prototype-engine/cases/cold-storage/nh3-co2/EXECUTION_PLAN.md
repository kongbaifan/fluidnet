### 3.3 状态与物理方程

**压缩机（强制流量）**

```text
m = capacity_ratio · m_rated · (rho_suction / rho_rated)        # 排量/载量/吸气密度
p_discharge 由高压侧网络求解（排气支路 + 高压贮液器压力 + 沿程损失），不预设
h_2s = f(p_s, s_s)                                               # 等熵出口
h_2  = h_s + (h_2s − h_s) / eta_isentropic
P    = m · (h_2 − h_s) + P_loss                                  # 压缩功（电功率另计损失）
```

校核：压比/排气温度/功率在包络内；载量变化率与最小启停时间由控制/模块约束；反向流与停机状态有明确事件。

**闭式容器（`M/U/V`）**

```text
M = M_liq + M_vap
V = M_liq/rho_liq(p) + M_vap/rho_vap(p)
U = M_liq·u_liq(p) + M_vap·u_vap(p)
dM/dt = Σ m_in − Σ m_out
dU/dt = Σ m_in·h_in − Σ m_out·h_out + Q − W
```

每步由 `(M, U, V)` 反求 `p` 与气液分配，再按几何换算液位；单相（过冷/过热）、空罐/满罐、气液转换设独立合同与事件；不允许把干度夹在 0–1 维持假平衡。

**板式换热器（一侧蒸发/一侧冷凝）**

```text
Q = m_nh3 · (h_nh3,out − h_nh3,in) = m_co2 · (h_co2,in − h_co2,out)
Q = UA · LMTD（或 ε–NTU，相变侧 C_r≈0）
约束：两侧温度夹点、出口干度/过热度、两侧压降
```

**冷风机**

```text
空气侧：Q_air = m_air·cp_air·(T_air,in − T_air,out)（或 ε–NTU）
制冷剂侧：Q = m_co2·(h_out − h_in)，出口干度/过热受限
库房：复用 A3 热节点与货物节点，Q 作为冷源项；风机启停影响换热与电功率
```

**液泵与支路**

```text
泵：Δp = A − B·m²（或厂家曲线），P = m·Δp/rho/eta；需汽蚀余量校核
节流阀：m = Kv·opening·sqrt(2·rho·Δp)（两相用均相密度，记录适用区间）
管道：均相压降（Darcy–Weisbach + 局部阻力 + 高差），记录滑移/干涸未建模效应
```

**相态与校核**

- 两相状态由 `(p,h)` 或 `(p,x)` 确定；饱和温度/压力用 REFPROP/CoolProp 反求；
- 过热度/过冷度不足、夹点越界、干度越界、包络外工况报明确诊断；
- 质量账本：每个工质 `ΔM = Σ流入 − Σ流出 − Δ库存`；能量账本：`ΔU = Σmh_in − Σmh_out + Q − W`，帧指标记录残差；
- 稳态初始化：先解单级稳态循环（独立参考一致），再进入动态。

### 3.4 求解与时序

- 未知量：节点压力 + 支路流量（强制流量支路给流量约束，容器节点给压力状态）；每个连通分量至少一个压力参考（容器或边界）；
- 方程：节点质量守恒、支路关系（管道/阀/泵/换热器/压缩机）、相态与包络约束；
- 求解：`scipy.least_squares`（dense 默认，sparse 可选），带缩放、阻尼、连续化和上一步热启动；两相边界附近用平滑/分段处理，失败时缩小步长/切分事件；
- 物性：REFPROP 优先（NH₃/CO₂），CoolProp 回退；缓存 `(p,h)`、饱和反求与局部导数，避免每轮全量查询；线程安全；
- 时间推进：容器 `M/U`、库房/货物温度用隐式 Euler；控制采样、阀门/压缩机启停、融霜状态转换按事件时刻截断子步；失败子步回滚状态、参数提案与累计器；成功步统一发布帧；
- 诊断：不收敛、相态越界、包络越界、账本漂移、物性不可用等给出可定位错误码；
- 性能目标：单次稳态 ≤2 s；2 h 仿真 fast 运行在现有动态量级内；24 h 目标沿用 PLAN 5.3 的 ≤5 min（B6 实测记录，不通过降低精度达标）。

### 3.5 控制与调度

- 语言：Python 项目控制脚本；不采用 LUA；
- 执行器合同：运行时可写数值参数（载量、开度、频率、设定值）；离散执行器（压缩机/冷凝器/风机/泵启停）在 B0 决定用 `0–1` 数值语义或扩展布尔 runtime，B3 前冻结；
- 五闭环：①压缩机载量→低压桶压力；②电磁节流阀→高压贮液器压力；③高压贮液器液位（2/3 上限、1/2+20 cm 下限、回气阀/节流阀动作）；④冷风机 PID（库温）；⑤CO₂ 供液泵变频（供液压差/流量）；
- 上层循环：根据低压桶/高压罐液位、总充注量、压缩机能力做启停与负荷分配、冷凝器启停；记录每次切换原因、时刻和回执；
- 约束：最小启停时间、载量变化率、液位/压力/温度包络、控制权冲突与手动/自动切换；
- 数据接口：控制脚本可读帧变量（含两相状态），写运行参数；采样周期与子步截断复用现有会话机制；
- 测试：控制方向、饱和/回卷、启停次数、无持续振荡、失败回退不重复计数。

### 3.6 前端与案例工作流

| 闭式容器 | `M/U/V` 方程与饱和反求联立（独立根求解） | 残差 ≤1e-8 相对；p/液位一致性 |
| 板式换热器 | ε–NTU 解析 / 能量平衡 | 数值能量残差 ≤1e-6；UA 法 Q 相对 0.5% |
| 冷风机 | 空气侧热量 + 制冷剂侧焓差 | 两侧能量 ≤0.5%；干度/过热边界 |
| 液泵 | 泵曲线/相似律 | 流量-扬程对照；功率 1% |
| 阀门/管道 | Kv 公式/均相压降公式 | 与解析计算对照；适用区间记录 |
| 控制 | 阶跃响应、方向、饱和、启停次数 | 进入目标带、无持续振荡、启停不越约束 |

### E. 术语

| 术语 | 含义 |
| --- | --- |
| 高压贮液器 | 冷凝后的 NH₃ 液体储罐，罐内保留气体用于压力调节 |
| 低压循环桶 | 低压侧气液分离与循环供液容器，压缩机从这里吸气 |
| 湿回气 | 冷风机出口含液滴/两相的 CO₂ 回流 |
| 循环倍率 | 供液流量与蒸发量之比 |
| 载量 | 压缩机当前容量比例（0–1） |
| 蒸发/冷凝压力 | 低压侧/高压侧饱和压力（蒸发/冷凝温度对应） |
| 需求满足度 | 文章定义的库温达标程度评分（AI 输入之一） |
