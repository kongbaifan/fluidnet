# NH₃ 制冷 + CO₂ 液泵载冷扩展

在单库房 A6 完成后按 [总计划 B 阶段](../PLAN.md#6-b-版向倍思鹿-nh₃co₂-冷库系统扩展)实施。目前尚未建立系统参数或计算模型。

正常回路采用 NH₃ 机组提供制冷，NH₃/CO₂ 换热器冷凝 CO₂ 蒸气，CO₂ 液泵向多库房冷风机供液。两种工质只换热，各自的质量与库存独立守恒。

开发顺序：多库房与公共冷源 → NH₃ 单级及闭式容器 → CO₂ 供液/湿回气 → 分层控制 → NH₃ 双级与中间冷却 → 热气融霜 → 系统验收。

进入 B0 时固定拓扑、设备参数、容器几何/充注量和验证日程。融霜压缩机、辅助乙二醇回路及油冷却等结构按案例需求单独确认。
