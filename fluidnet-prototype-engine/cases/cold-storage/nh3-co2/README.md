## 目标拓扑（摘要）

正常回路采用 NH₃ 机组提供制冷，NH₃/CO₂ 换热器冷凝 CO₂ 蒸气，CO₂ 液泵向多库房冷风机供液；两种工质只换热，各自的质量与库存独立守恒。另按阶段加入单级→双级压缩、闭式容器、乙二醇辅助回路（可选）和含压缩机的融霜回路。

开发顺序：两库房与公共冷源（B0）→ NH₃ 单级与闭式容器（B1）→ CO₂ 液泵/湿回气主回路（B2）→ 分层基础控制（B3）→ 双级与中间冷却（B4）→ 融霜与恢复制冷（B5）→ 完整案例与校核交付（B6）。

## B0 设计决策（2026-10-20，按倍思鹿案例冻结）

- 设备：完整 6 台 NH₃ 压缩机（4 单级 + 2 双级）、蒸发式冷凝器、高压贮液器、低压循环桶、NH₃/CO₂ 板换、CO₂ 液泵；
- 库房：2 个相同库房为基线（截图 5.6 版 3 组控制器作为差异记录，待项目文件确认）；
- 乙二醇 −10 °C 辅助回路：纳入，作为受限单相辅助回路；
- 融霜：含压缩机的独立融霜回路（非 NH₃ 热气旁通），具体拓扑/时序 B0 冻结；
- 画布：16 页多画布 + 跨页连接，每页 96–128 设备；
- 集成：单一项目、同一制冷执行域（`refrigerant` + `thermal` 端口）；
- 开发顺序：串行分阶段 B0→B6，不在 A2 后并行；
- 不采用：LUA（继续 Python）、可训练 AI（B6 后另立研究）、与倍思鹿的数值对测。

详细依据与工期影响见 [BASELU_CASE.md 第 11 节](BASELU_CASE.md#11-b0-决策冻结2026-10-20按倍思鹿案例) 与 [EXECUTION_PLAN.md 第 9.0 节](EXECUTION_PLAN.md#90-已按倍思鹿案例冻结2026-10-20)。
