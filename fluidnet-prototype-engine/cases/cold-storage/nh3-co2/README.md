## 目标拓扑（摘要）

正常回路采用 NH₃ 机组提供制冷，NH₃/CO₂ 换热器冷凝 CO₂ 蒸气，CO₂ 液泵向多库房冷风机供液；两种工质只换热，各自的质量与库存独立守恒。另按阶段加入单级→双级压缩、闭式容器、乙二醇辅助回路（可选）和含压缩机的融霜回路。

开发顺序：两库房与公共冷源（B0）→ NH₃ 单级与闭式容器（B1）→ CO₂ 液泵/湿回气主回路（B2）→ 分层基础控制（B3）→ 双级与中间冷却（B4）→ 融霜与恢复制冷（B5）→ 完整案例与校核交付（B6）。
