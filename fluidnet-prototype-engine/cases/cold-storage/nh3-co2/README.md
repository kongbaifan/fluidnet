## 范围（2026-10-20 按原文深度收缩）

倍思鹿原文物理部分只到“强制流量压缩机、非定压罐体”层次，主体是五闭环 + 上层启停控制，结果只有“输入两个压力目标即可长时间稳定自运行”一句。B 按这个深度做：

- 设备：4 台相同单级 NH₃ 压缩机、蒸发式冷凝器（2 组风机）、高压贮液器、电磁节流阀、低压循环桶、1 台集总 NH₃/CO₂ 换热器、CO₂ 容器与液泵、2 个相同库房（每库 1 组冷风机）；
- 模型：集总制冷站执行域，3 个容器 `(M, U)` + 2 个库房温度共 8 个状态，不进通用管网，两相物性只在设备内部查询；
- 控制：五闭环 + 上层启停（Python + PID），目标蒸发/冷凝压力可写，反馈能耗与需求满足度；
- 画布：现有 8 页上限内布局；
- 阶段：B0 参数与参考 → B1 制冷站执行域 → B2 分层控制 → B3 案例交付，20–31 人日。

依据见 [BASELU_CASE.md 第 11 节](BASELU_CASE.md#11-b-范围2026-10-20按原文深度收缩)。同日较早的完整设备清单版本（6 台压缩机、乙二醇、融霜、16 页画布，中值 78 人日）保留在提交 `3dc1674`。
