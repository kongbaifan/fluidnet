# 冷水机组与房间风水联算

本例连接空气、冷冻水和冷却水三个独立回路。盘管的冷量取决于真实水温和水量，机组的耗电与能力取决于制冷循环和冷却水状态。参数是教学假设，可修改并复算。

## 从界面运行

1. 启动源码服务，进入左侧“风系统”。
2. “创建风侧示例”选择“冷水机组与房间风水联算”。默认动态运行 20 s，步长 2 s；“湿空气设置”可以改时长或切到稳态。
3. “风量与状态”分别显示空气和液体端口；“湿空气状态图”只显示空气点。
4. “设备与水耗”查看盘管冷量、凝水、机组制冷量/COP/负荷比/累计耗电、房间温湿度和冷却塔补水。
5. 在“编辑拓扑”双击机组，将“冷冻水出水设定”从 7°C 调到 9°C，应用后重新运行。盘管冷量和凝水会随水温改变；旧结果会标记过期。
6. 保存项目后可以重载复算。CSV/HTML 导出取所选运行的冻结目录与接受帧；规范与 Studio 导入文件见[算例目录](../examples/air-side/README.md)。

## 回路和端口

| 设备 | 第一条通路 ch0 | 第二条通路 ch1 |
| --- | --- | --- |
| `water_coil` 冷/热水盘管 | `in0 → out0`：湿空气 | `in1 → out1`：液体 |
| `water_chiller` 水冷冷水机组 | `in0 → out0`：冷冻水 | `in1 → out1`：冷却水 |

空气回路：新风与回风 → 混合箱 → 过滤器 → 水盘管 → 风机 → 房间 → 回风/排风。示例保留再热与加湿器，功率和加湿量均设为零。

冷冻水回路：泵 → 机组蒸发器 → 水阀 → 盘管水侧 → 回泵。冷却水回路：泵 → 机组冷凝器 → 湿空气冷却塔 → 回泵。

默认工质保持 `Air/gas`，通过 `circuit_fluids` 分别为机组的 `in0`、`in1` 指定液态 Water。两条水回路不能相连；空气与液体不能通过普通节点混合。水回路压力参考只提供初始温度种子，闭式循环稳态的温度由真实热平衡决定，不提供补水或隐藏冷源。

## 计算和能量含义

- 盘管采用逆流干湿分段 ε–NTU，湿段用焓差传热、刘易斯数取 1。干湿交界由表面温度与进风露点确定。热水工况可以加热空气，无水量时不交换热量。
- `Coil.total_heat_w` 是空气焓降，`Coil.water_heat_w` 是液体得热；两者之差为凝水带走的焓。空气按干空气质量输运，公共端口流量仍是当地湿空气总量。
- 机组复用单级蒸气压缩循环，蒸发器/冷凝器按等温制冷剂侧效能换热。未满载时控制冷冻水出水设定；满载仍不足时 `capacity_limited=true`，出水温度上漂。
- `Chiller.condenser_heat_w = Chiller.cooling_power_w + Chiller.shaft_power_w`。电机损失排向机房，因此 `electric_power_w` 高于轴功；COP 为制冷量/电功率。
- 冷冻水泵轴功进入水，所以稳态机组制冷量等于盘管水侧得热加泵功。冷却塔排热等于机组冷凝排热加冷却水泵功。
- 累计制冷量、耗电、凝水和塔水耗只在接受子步时积分，失败或缩步不重复累计。房间温湿度和热容沿用隐式 Euler 推进。

## 接口与批量比较

`GET /api/v1/examples/chiller-air-loop` 返回完整规范项目。通过既有 `/api/v1/runs` 运行；观察键例如 `Chiller.cooling_power_w`、`Chiller.cop`、`Chiller.state.electric_energy_j`、`Coil.water_heat_w`、`Room.state.temperature_k`、`Tower.makeup_kg_s`。

既有批量工况支持扫描机组设定、额定能力、水阀开度和室内负荷；目录区分空气与液体，液体通路不声明含湿量或干空气质量流量。历史运行保留当时的字段、单位和假设。

## 模型范围

机组负荷比连续取 0–1，不模拟最小负荷启停、设备选型性能图或制冷剂管网动态。液体回路为无储量代数网络，风水联算暂不支持水箱、困液或水管热容；关机且仍有持续净热源的闭式无储量回路可能没有稳态解。盘管不支持结霜或反流，机组两侧不支持反流，有制冷需求但冷却水零流量时明确拒绝。示例可手动调设定/水阀，未配置房间恒温控制。
