# 暖通空调与冷水机房基础设备补全清单

核对日期：2026-11-02。源码基线：`31f1da9`。

范围：常见水冷中央空调的冷冻水、冷却水、空气处理和末端系统；冷水机组按整机设备表示。供热、风冷机组和变风量系统列为按需求增加的项目。

状态依据当前设备目录、模块源码及既有验收文档。本文是候选补全清单，优先级不表示已开始实施；**本轮随后的实施内容见[暖通基础设备与理想测点](HVAC_BASIC_EQUIPMENT.md)与[验收记录](HVAC_BASIC_EQUIPMENT_ACCEPTANCE.md)**。

## 1. 状态与优先级

- **已有**：已有设备模型和使用或验收记录，可作为基础复用；不表示所有工程工况均已验证。
- **完善**：已有模型，但几何、运行工况或工程参数仍需补充。
- **等效／模板**：现有部件能表达基础作用，需要规范设备合同、型号、图形、组合或控制模板。
- **新增**：未发现对应的正式独立设备模型；部分基础关系可能已有。

优先级分为：**第一批**（标准机房与末端组网）、**第二批**（物理细节与设备运行完整性）、**按需**（由具体系统选型决定）。

## 6. 补全后应能搭出的基础案例

1. **标准冷水机房**：水冷机组、冷冻水泵、冷却水泵、冷却塔、分集水器、过滤器、关断／止回阀和多个末端；逐回路检查流量、压差和热量关系。
2. **水力平衡案例**：至少两条不同阻力的末端支路，调节平衡阀得到目标分配；总流量与支路流量一致。
3. **三通阀案例**：分流和混流两种接法，覆盖开度两端、中间开度和反向压差；混合温度按焓和质量守恒计算。
4. **泵切换案例**：停泵、备用泵投入、止回阀截止和参数切换；结果要反映定义的被动阻力与隔离行为。
5. **空气处理末端案例**：新回风、过滤、风机、水盘管、房间和温控；湿工况检查凝水及空气／水能量关系。
6. **定压／膨胀／补水案例**：在对应模型完成后检查压力变化、容纳水量和实际补水账；压力参考点不作为隐含质量或热量来源。

新增基础设备最终应覆盖拖入、连接校验、参数单位、运行、结果、保存重载与版本绑定。是否需要新增求解器关系，应在具体设备设计时确定；设备名称或图形不同不自动要求增加一种算法。
