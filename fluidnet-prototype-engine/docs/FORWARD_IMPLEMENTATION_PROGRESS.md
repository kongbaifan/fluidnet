## 使用与边界

- 模块页“设备组与选型”创建可编辑参考项目；设备参数页选型/几何设计只填草稿，确认后生效。
- 建模工具栏提供组操作与全项目查找；Shift多选/框选；运行中禁止改拓扑，复制预览明确外连与控制/历史引用的处理。
- 系统检查定位合同/连接问题；运行记录可看系统结果解释、工作点、末帧差值和原报告。
- 耦合工具栏“联算模式”显式选择storage_v1，最多8关系和有限缓冲储热；旧模式保留2关系同容器约束。
- 新管束管程限定单相、无持液；壳体唯一M/U在显式容器。高度取口相态不符减步/拒绝，不模拟连续穿越事件。几何盘管的h/f/K为有来源输入，不构造厂家数据库。
- 制冷组合只封装完整闭合、单纯工质内置组，无对外开放口；新SDK0.9能力不改变旧schema解释。跨域储热暂不包含任意储量设备或自适应耦合状态。
- 300实例速度来自简单单相开发参考，每规模单次观测，不外推到复杂制冷/Worker网络。
