## 设置覆盖

| 页签 | 检查的设置与操作 | 当前行为 |
| --- | --- | --- |
| 项目属性 | 名称、说明、添加画布、重命名画布 | 名称不能空白；直接点击保存即可提交当前输入；顶部项目名称同步更新；画布修改保存重载一致。 |
| 介质与单位 | 默认介质、物性字符串、质量/摩尔基准、相态策略、回路工质的添加/删除/修改 | 显式物性字符串覆盖预设；清空后回到预设；旧 `fluidConfig` 字段正确显示；只提供流体及制冷剂端口，失效端口明确保留待修。 |
| 运行与求解 | 稳态/动态、计算节奏、速度倍率、仿真时长、持续运行、输出间隔、最大迭代、物性反馈、水力算法、质量/压力容差 | 合法值进入后端请求；动态专属设置按模式启用；创建、求解、运行和暂停期间锁定不可热更新的物理设置；停止后可修改。 |
| 界面与布局 | 主题、模块数值显示精度、画布点阵、恢复窗口位置 | 显示偏好即时生效并在当前浏览器记忆；精度用于模块与设备变量，不修改模块定义、冻结快照或实际数值。 |
| 保存与交换 | 保存设置/原型、导出原型/型号库/变量表、导入原型/型号库、恢复示例 | 正常往返、错误文件、更换文件、异步读取、取消和大文件边界均有检查；恢复示例前保留原草稿备份。 |

项目标识、工程单位方案、单位对照和快捷键说明属于只读内容。稳态的“运行”只求解一个工况，“单步”沿用动态推进语义；界面已说明这一点。

## 发现与处理

| # | 原问题及实际影响 | 处理 |
| --- | --- | --- |
| 1 | 暂停后修改步长、时长、模式、容差或介质，界面显示新值，继续/单步仍使用后端旧配置。 | 物理设置统一按运行状态禁用，事件处理再次检查；运行状态与设置显示保持一致。 |
| 2 | 动态运行提交期间没有进入求解中状态；修改设置后，迟到的启动回执可能留下未被界面接管的后台运行。 | 创建阶段保留旧结果并显示求解中；先创建暂停任务，确认归属后再继续/单步。取消、过期或替换后的回执按运行 ID 收尾；失败恢复旧结果，清理失败保留可控制的运行。 |
| 3 | 速度倍率填空、0 或 101，产生未处理异常且没有正常校验提示。 | 使用统一校验和错误提示，恢复原有效值，不产生页面异常。 |
| 4 | 稳态仍可开启持续运行，快速计算仍可调整无实际作用的速度倍率。 | 稳态禁用动态专属选项；快速计算禁用速度倍率；切换模式保留已有动态偏好。 |
| 5 | 湿空气项目可切到不支持的参考物性，导致 `AIR_SOLVER_OPTIONS`；物理配置对话框也缺少创建阶段保护。 | 湿空气禁止参考物性并提示需要温度与密度联算；打开及应用湿空气设置前均检查运行状态。 |
| 6 | 项目名输入的防空保护被 change 处理覆盖，空名可保存并重载。 | 修改时校验非空名称，拒绝空白并恢复原值。 |
| 7 | 编辑说明等文本后直接点击页内保存，失焦重绘替换按钮，第一次点击被吞掉。 | 无需联动的文本和数字修改不重建页面；单独更新顶部项目名称，保留保存按钮。 |
| 8 | 旧文件只含 `fluidConfig.fluid/reference` 时，设置显示空字符串/质量基准，实际计算却用隐藏工质/摩尔基准。 | 规范化时仅补缺失的顶层可见字段，保留显式清空覆盖值的语义。后端桥接原本符合此约定，无需修改。 |
| 9 | 回路工质可选择库房热接口等不能承载工质的端口；失效引用可能被下拉框外观掩盖。 | 只列 `fluid` / `refrigerant` 端口；没有可用端口时不能添加；失效引用显示占位，不静默换成其他端口。 |
| 10 | 设置页改变库模块精度，设备却读取冻结快照精度，选择 8 位后仍显示 4 位。 | 改为独立浏览器偏好 `ui.modulePrecision`，支持按模块定义及 2/4/6/8 位，所有相关变量显示使用同一来源。 |
| 11 | 导入预览校验写入全局参数定义，失败或取消后仍影响当前模块。 | 验证阶段不再修改全局 `PARAM_DEFS`，正式应用前保持当前工作区不变。 |
| 12 | 合法文件 A 换成无效文件 B 后仍能应用 A；旧异步读取也可能覆盖新选择。 | 每次选文件清除旧解析结果；校验文件身份、读取序号及弹窗归属；读入或出错时禁用提交，提交时再次检查。 |
| 13 | 正常运行后的原始导出文件超过 5 MB，软件无法导入自己导出的文件。 | 上限与工作区对齐为 64 MiB；格式化文本超限而完整紧凑文本可容纳时自动紧凑导出，不裁剪数据。真实约 8.3 MB 原始文件已完成往返验证。 |
