# 界面说明清理

日期：2026-11-12。基线为 `edb8c2d` 上的当前工作区。本轮在用户确认全项目清理范围后实施，前一批文档改动继续保留。

## 改变后的界面

- 设备总览、参数、连接和模块编辑页移除“怎么连接与调节”说明块、重复端口释义及字段下方教学文字。参数名称悬停可查看取值说明，模块库的“说明”入口提供完整模型和验证信息。
- 待应用数量为 0 时隐藏；编辑产生草稿后显示，应用后重新隐藏。已应用值、当前采样、控制接管、结果来源和错误反馈继续显示。
- 首页移除“当前体验范围”长介绍，消息区只在有非示例消息时显示。项目、模块、控制、设置、曲线和批量等页面移除常驻教学副标题。
- 设置页保留 REFPROP 检测状态，移除安装路径与科普段落；保存、导入和导出按钮统一使用“工作区”，数据格式和操作标识保持兼容。
- 库值物性配置、串口演示及映射配置仍有简短能力标记。风系统模型细节按需展开，干空气质量基准保留；冷库普通工况弹窗移除内部验收编号。
- 设备组弹窗只显示所选模板的按需说明；批量、型号、选型、连接、导入和泵曲线等辅助页面减少重复文字。
- 模块验证台、错误诊断和使用指南继续保留专业说明。保存失败、未持久化、结果过期、断连、参数越界、控制接管等实际问题不属于删除范围。

合并前补充：PR #11 的远程 CI 发现部分旧浏览器脚本仍按未压缩 JSON 读取草稿，另有三处断言依赖已经移除的说明或旧输入名称。本次统一改用既有草稿解析器，更新目录、模块编辑及导入断言，并让基础单步测试等待相应历史帧保存后再核对数值；物理数值与守恒断言保持原标准。远程复验结果以该 PR 的 Checks 为准，本地浏览器权限限制不变。

后续复验补齐大旧草稿的备份容量边界：只有备份遇到容量不足时，才尝试无损压缩已存草稿并重试；不会删除历史或覆盖为待载入数据。加热器测试按当前目录补齐默认参数，双盘管案例等待初始化完成，126 设备文件往返采用创建副本；大工程替换时若浏览器仍无法容纳备份，继续保留原数据并明确拒绝，不把这一路径登记为已通过。
