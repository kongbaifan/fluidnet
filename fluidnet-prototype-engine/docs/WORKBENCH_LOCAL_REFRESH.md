# 工作台局部刷新与运行交互验证

2026-11-07，基线 `8cfabe1` 加本轮工作区改动。原有拖动增量更新和普通采样的局部刷新继续保留；本轮减少非结构操作和运行状态变化引起的整页替换。

## 更新边界

`workbench-refresh.js` 接收项目、当前页、UI 状态与展示回调。先检查页面／项目身份、当前页实际绘制的节点和连线，再更新 viewBox、选中状态、接线起点、缩放读数、模块库／网格／曲线显隐、撤销重做及运行按钮。节点或本页连线增删仍回退既有完整渲染。跨页连线只有两个端点都在本页时计入绘制集合，避免分页工程在每次拖动结束时误判结构变化。

以下操作已使用局部入口：边选择、组选择、接线起点与取消、缩放／适应画布／网格、模块库开关、同屏曲线开关、拖动与平移提交、运行开始／暂停／继续／停止。操作仍调用原项目状态入口登记编辑或撤销，不改变模块参数和数值输入。

`svg-dom.js` 对生成的 SVG 按节点、边、端口和曲线系列身份复用 DOM，更新属性、文本和必要子节点。观察量、连线动画、路由以及图表路径变化无需替换整个 SVG；重算尺寸也保留图表根节点。画布渲染仍为 SVG／DOM，没有新增框架或渲染库。

普通参数输入不进入 SVG 对账范围。选择侧栏只在生成内容变化时更新；运行中参数浮窗保持原输入节点。右键菜单在动作分派时单独关闭；任务抽屉单独同步，终态不留下仍在运行的任务按钮。选择同步与画布绘制各执行一次，避免重复 paint。

## 针对性验收

`workbench-refresh.test.mjs` 的 5 项公开工厂测试覆盖切项目／页／路由拒绝、结构变化回退、跨页绘制集合、七种运行状态、原画布和图表对象复用。浏览器流程在真实 DOM 上另行验证身份、焦点与数据，不能用 stub 通过代替实际交互。

```powershell
$env:PYTHONPATH='backend'
node tests/browser-canvas-performance.mjs --live
```

真实 Edge 浏览器，1920×1080，DPR=1；30/64 台单页，100/300 台分为 2/5 页，当前页上限 64 台。项目由压力边界与双端口水管串联组成，经正式导入入口加载。未通过脚本改写应用状态。

每规模先执行三轮双节点拖动、撤销重做、平移、缩放与保存，再开启真实持续运行、质量流量色标、数值标签、动画和同屏曲线。运行期间输入压力源参数草稿，等待采样推进，确认输入节点、焦点和草稿仍在；然后验证选择、边焦点目标、缩放、模块库切换、拖动、暂停／继续／停止、右键菜单关闭及任务抽屉终态。每次拖动结束仍核对连线端点和原节点身份。
