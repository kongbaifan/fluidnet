## 1. 交付与范围

SDK API 预览版本由 0.1.0 更新为 **0.2.0**。新增六个带单位、仅关键字参数的公共函数：管道/阀/局部阻力压降、K 到 Kv、质量流量与体积流量双向换算。入口、单位、范围及异常合同见 [SDK API](../SDK_API.md)。函数只依赖标准库，密度由调用者明确提供，不导入引擎或查询物性。

`backend/fn_sdk/_hydraulic_core.py` 提取旧引擎的标量公式，公共工具添加输入与数值范围校验；`backend/fn_engine/hydraulic_derivatives.py` 的既有入口和导数基础项复用该核心。原参考常数、运算顺序、过渡区公式及导数分支保留。没有改变求解迭代、收敛容差、模型字段、Worker 协议或已发布种子模块源码/版本。

Protocol 与实际宿主构建器增加 `ctx.net.resistance(channel=..., diameter_m=..., loss_coefficient=..., density_kg_m3=None, heat_w=0.0)`，使用既有 resistance 关系合同。默认密度编码为原有参考物性标记 0；K=0 不被截断。关系没有高差项，不接受 `height_m`。新增 `examples/module_sdk/resistance.py` 作为带类型的作者示例；它不是已发布的新模块版本，正式版本仍待 S4。

## 2. 公式与边界决策

- 局部阻力使用 `Δp=K*m*|m|/(2*ρ*A²)`，`A=πD²/4`；正负流量按声明通路方向计。
- Kv 定义为 `Δp=100000*(ρ/1000)*Q*|Q|/Kv²`，Q 单位 m³/h；转换为 `Kv=3600*sqrt(200)*A/sqrt(K)`。旧 pipe_fitting v1 的近似常数 50912 和 K 下限保持原样，新转换函数不承诺与旧包的舍入近似完全相等。
- 管道沿用 Poiseuille/Haaland 和 Re=2300–4000 的压降线性混合；过渡点值连续，不宣称全局可微。
- 公共函数拒绝布尔、非数值、非有限值、无效范围，以及溢出或应为非零却下溢成零的结果。密度、黏度、直径、管长及 Kv 为正，粗糙度/K 非负；流量可为正、负或零。
- 阀开度要求 `0<opening≤1`；关阀是约束，不能靠压降函数计算。K=0 有零局部损失，但不存在有限等效 Kv，因此转换函数拒绝 K=0。

这些工具不包含高差、轴功、热量、流量反解或新物理包络。可信的引擎残差路径使用内部核心，保持原校验和失败行为，不在每次残差计算重复公共输入校验。
