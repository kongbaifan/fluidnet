# 设备选型、型号保存与实例草稿

2026-11-05。入口为设备参数面板“设备选型”。流程采用实例绑定的冻结模块版本，调用现有`POST /api/v1/modules/design`；Python模块提供`design.py`才可计算，无设计函数的设备会说明如何增加并发布设计能力。

## 操作

1. 打开设备参数面板，点击“设备选型”。设计输入初值来自设备待应用草稿；参数按冻结合同显示名称和单位，支持数值、布尔、文本、曲线。
2. 显式选择设计工质：项目工质或已配置的回路工质。多回路设备的设计函数当前仍只有一个`ctx.fluid`；由作者明确此次设计使用哪一侧，不隐式推断双侧工质。
3. 计算后并列显示已应用值、设计输入和设计结果及单位。设计函数日志显示物性/模型假设；计算和预览均不修改设备与型号。
4. 选择“仅填入设备草稿”或“保存型号并填入设备草稿”。后一方式记录绑定模块版本、源码/定义哈希、设计源码哈希、规范单位输入和设计工质。
5. 回到面板，通过原有“预览并应用/确认应用”改变实例设置。运行中仍由后端校验参数权限、控制接管与原子写入。

取消不写入；计算中取消后迟到响应被丢弃。计算期间或确认前实例、草稿、绑定模块、工质、项目被替换时拒绝过期方案。选型型号应用或插入其他设备时检查模块版本和双哈希，不能静默应用到不同模块版本。

保存型号发生在当前工作区草稿中，沿用工作区持久化。设计函数返回的是参数建议，不能把设计目标直接当运行结果；模块目录更新不改变项目已绑定的设计源码。

## 可直接使用的示例

模块库新增独立`design_valve` v1“流量压差选型阀”，不替换任何旧阀版本。选择模块卡片“管网案例”可得到可编辑设备及边界；打开V1进行选型。

设计条件：目标体积流量（m³/h）、压差（kPa）、进口绝压（kPa）、液温（°C）和阀门开度（%）。按入口密度反算线性阀Kv，并以出口等焓物性检查液相。运行依然使用原生阀关系和实际端口，不使用设计流量强制求解。完整假设见[示例说明](../modules/design_valve/README.md)。

这不是完整厂家选型数据库；未包含名义口径推荐、气蚀/噪声/闪蒸/阀权度验算。选择其他设备需其作者提供相应设计函数，界面不拼凑通用选型公式。
