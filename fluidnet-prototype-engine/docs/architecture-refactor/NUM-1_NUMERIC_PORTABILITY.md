# NUM-1：跨 CPU 数值稳定性

2026-11-04 用户批准追加此工作包，作为架构整理 AR-7 的前置验收。原始失败证据为 [默认／Haswell 同机对照](https://github.com/kongbaifan/fluidnet/actions/runs/41634926268)：默认 2 failed，Haswell 2 passed。原物理方程、误差容差与接受事务继续保持。

## 极小泄漏止回阀网络

本机设置 `OPENBLAS_CORETYPE=Sandybridge` 可以复现默认 CI 的同一失败：压力残差 1.09458 Pa、质量残差 0.00276286 kg/s。混合 Jacobian 的第一轮用完 80 次迭代时，压力误差约 0.819 Pa、质量误差约 1.42e-8 kg/s；接近解但尚未满足原质量门槛 1e-8 kg/s。原有有限差分后备路径重新从冷初值开始，丢弃了已取得的进展，并落入止回阀关闭附近的停滞点。

修复仅调整已有后备路径的初值：当上一轮明确达到迭代预算上限且末次试算有限时，从末次试算继续；驻点假收敛等其他失败仍用冷初值。没有增加重试次数，也没有接受中间试算。每轮仍受项目 `max_iterations` 限制，最终必须通过原压力、质量与有限值检查。新增回归模拟首轮预算耗尽，核算串联阀的独立 Kv 解；另验证两轮都耗尽时仍拒绝未收敛结果。
