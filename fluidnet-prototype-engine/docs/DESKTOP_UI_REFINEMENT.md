# 桌面界面优化记录

日期：2026-11-12。分支：`codex/desktop-ui-refinement`。

目标是把现有建模平台整理为适合长期操作的桌面工作区，继续使用真实设备、参数事务和计算结果。1920×1080 是主要验收视口，同时检查较小窗口的入口可达性。

## 观察与调整

原界面将项目、模块开发、结果分析和外部接口等十二个入口排列在同一条窄导航中。运行按钮浮在画布右侧中央，浮窗边界必须额外避让；首页的新手引导占据项目列表之前的主要位置。

本轮调整如下：

- 导航分为“工作区”“结果与分析”“设备与扩展”，桌面宽度下采用图标与横排文字；设置和指南固定在末尾。模块编辑与节点定义正确标记所属的模块导航。
- 首页先展示最近项目和常用模块，提供“继续建模”；示例与模块开发引导移到右侧。
- 运行、暂停、单步、停止、同屏曲线和运行设置集中在顶部工具条。其后依次是画布页签、建模工具、扩展工具和物理显示，中央画布、右侧参数、下方曲线各有明确位置。
- 浮窗的上边界按画布起点计算，保证设备窗口不覆盖运行工具条。保留停靠、拖动、缩放、置顶和保存恢复。
- 保存反馈移至页脚，仍显示保存中、未保存修改、成功和失败状态。
- 使用浅灰工作区、白色工作表面和较小圆角；沿用橙色选择状态、绿色运行状态与实际工质颜色。调整同时适用于深色主题。
- 小窗口保留紧凑导航，备份、载入和保存采用图标入口；工具条仍可操作。

主要实现位于 `frontend/desktop-workspace.css` 和 `frontend/studio.js`，样式由 `frontend/index.html` 加载。

## 验证

- `npm run check`：通过。
- `npm run test:ui`：384 项通过。
- `tests/browser-device-windows.mjs`：拖动、缩放、停靠、置顶、收起、最大化、重新打开、保存与重载通过。
- `tests/browser-device-guidance.mjs`：泵、阀、管道与传热的实际计算、草稿保持、参数字段和重载通过；运行工具条与浮窗不重叠。
- `tests/browser-desktop-workspace.mjs`：单步产生真实结果，保存反馈可持续更新，模块子页归属正确，1280×800、760×800、390×844 的全部导航及顶部操作可达。页面脚本错误为空。
- 注册新浏览器用例后，浏览器分组、影响范围与快速 CI 的 23 项检查通过。
- 浏览器实际查看了 1920×1080 首页和建模页、1280×800 与 760×800 建模页，以及计算完成后的深色主题。

新增用例已注册在工作区回归组，可在 Python 3.11 或更高版本的兼容环境中运行：

```powershell
npm run test:browser:desktop-workspace
```

截图与视口记录生成在 `artifacts/desktop-workspace/`，包含 `home-1080p.png`、`workbench-1080p.png`、较小窗口截图及 `verification.json`。

## EXE 交付边界

本轮交付的是界面骨架与操作布局。当前启动入口仍是 Python 计算服务与浏览器页面，尚未引入桌面宿主或生成 EXE。桌面封装还需落实窗口与服务的共同启停、用户数据目录、文件导入导出、发行资源和安装包。项目页的多种示例入口、模块开发各子页与结果报告的进一步信息整理，可在这套骨架上继续做具体页面优化。
