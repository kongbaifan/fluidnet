# 风水域混合缓冲箱设计卡（S6-1）

2026-11-06。新增`hydronic_buffer_tank`，复用既有`closed_buffer_tank`的定热质量、M·h显热储存和有限温区，不改旧模块只用于普通fluid的合同。

两液体端口、水力局部阻力、独立液体工质回路；湿空气项目中必须位于水侧。初温决定接受状态，压力由水网决定，不提供压力参考。质量流量进出相等，无净质量积累、气垫、分层或热膨胀。

纯候选方程沿用 `M(h_new-h_old)/dt = |m|(h_in-h_new)+Q-UA(T_new-T_ambient)`。在湿空气热输运每次候选迭代中，以同一旧h和dt求混合液新h；向节点传播流出焓。整个风水网络接受后才统一提升buffer cell状态和房间热湿状态。零流继续储热/散热，但不产生管口输运；初始帧固定初温且不累计时间。

运行账本中设备流股换热=m(h_out-h_in)，应独立等于外热−环境散热−储热；湿空气全网账继续核对实际流股，额外公开buffer库存变化和局部残差。普通fluid路径仍可用现有隐式解。

拒绝稳态求解、关闭热力、空气端口、跨相和超温；失败不推进任何接受状态。独立验证覆盖真实水盘管与湿空气网、温度阶跃、零流散热、反流、失败候选、保存与重载。风水其他水箱/困液/分布管热容不因此开放。
