# S3 多选编辑、查找与草稿容量

日期：2026-11-06。入口位于建模工具栏“多选与设备组操作”和“全项目查找”。本轮使用现有连接、冻结模块和保存合同，不修改设备方程或求解容差。

同日后续新增 [工程画布交互测量](CANVAS_INTERACTION_PERFORMANCE.md)，覆盖拖动节点身份、端点、平移缩放和帧间隔；下文保留此前容量/保存测试的原始口径。

## 设备组操作

- Shift+单击切换选择；Shift+在画布空白处拖动按设备中心框选。操作窗口也可跨画布勾选设备。
- 左/顶对齐、水平/垂直均匀分布只改变位置。跨页移动保留设备ID、参数、连接、控制和观察引用，连线按源设备所在页重新归属。
- 复制先显示实例ID映射、内部/外部连线数量。内部连接使用新ID重建；外部连接不复制，副本空端口需要明确接线。
- 只有引用全部位于选择内的测点、热耦合和选中工质锚点随副本重映射。部分选择的关系保留原对象。控制器、脚本、工况覆盖、历史和曲线仍绑定原设备，预览明确说明，不自动改写脚本源码或复制运行状态。
- 副本保留设备已应用参数、待应用草稿和型号/模块绑定，物理状态在新运行中独立初始化。复制不会复制历史累计值。
- 移动、复制、对齐都有撤销/重做。撤销快照补充测点与工质锚点，避免仅撤销设备却留下新引用。运行/暂停状态下禁止这类拓扑编辑。
- 继续采用每页64台、每项目8页的现有约束；不通过放大上限宣称容量已经验证。

全项目查找支持实例编号/名称、模块、画布名、声明的回路工质锚点以及最近编译回路归属。选择结果可切到对应画布并打开设备。未运行的回路没有推断结果时只按已有声明查找。

## 无损本地草稿格式

当前工作区重复保存模块源码、定义、版本和项目快照。本轮先测体积再增加`fluidnet-local-draft-v2`本地封装：把JSON容器和值编码为有向无环索引，相同源码/对象结构只存一次，恢复时重新构建独立对象，不令两个实例共享可变字典。

`persistLocal`与旧草稿备份先尝试原JSON；只有配额异常才尝试较小的无损封装。旧小文件继续原格式；启动可读取两种格式，旧备份导出时解包成正常JSON。若两种无损写入均失败，继续原有显式历史裁剪/内存保留提示，不能默默丢参数草稿。未删除任何已有备份；没有把服务端SQLite改为浏览器唯一来源。

解码限制索引、节点数、深度、展开规模和后向引用，拒绝循环、重复字段及未知类型。配额失败不先删除旧值。文件导入/项目导出仍采用原Project/工作区JSON，新的本地封装不改变物理合同或版本哈希。读取localStorage的开发工具应使用`FluidNetDraftStore.parse`，不能假定主键永远是原始工作区JSON。

## 实际验证

`tests/project-editing.test.mjs`新5项，加既有项目状态/草稿缓存11项，共16项通过；涵盖内部连接和测点/耦合/工质锚点重映射、复制独立性、容量拒绝不部分移动、撤销、运行锁、无损恢复和损坏数据拒绝。

`tests/browser-project-editing.mjs`在隔离服务中真实导入30/100/300实例的水侧串联参考项目，每页最多60台；执行全项目查找、跨页定位、对齐、保存、导出、刷新。另验证组复制、实际Shift单击及Shift框选、跨页移动、撤销/重做、真实浏览器配额下无损保存恢复；另注入工作区服务507拒绝保存与读取，刷新后仍从本地DAG恢复未应用草稿（管长已应用1m、草稿2m保持独立）；pageerror为空。规范项目通过真实`POST /solve`求解，未调整原容差。
