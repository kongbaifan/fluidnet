# 时间误差控制跨执行域验收

日期：2026-11-08。开启方式仍为 `solver.time_step.enabled=true`。原项目缺省继续固定步长。

## 本次接入

| 执行域 | 用于误差接受的物理量 | 事务边界 |
| --- | --- | --- |
| 普通流体 | 水箱质量、相对初始比焓的总能量；闭式缓冲和管段分段储热；困液 M/U | 完整控制/输出分段；细步成功后才提升库存、脚本状态和累计量 |
| 原生风水 | 房间水蒸气质量、空气与附加热容总能量、温度；水侧同上 | 湿度、热量、设备累计账随细步一起接受 |
| 冷库 A | 库温与货温；整步和两个半步均重新求机组工作点 | 日程、门负荷、启停、融霜模式、脚本和累计量一起回滚 |
| `storage_v1` 热耦合 | 制冷剂 M/U、库温、缓冲水箱 `mass_kg × h`，检查容器压力 | 沿用制冷站完整分段事务；缓冲焓按 J 容差检查 |

所有执行域均比较同一接受状态出发的整步与两个半步。第二半步从第一半步物理状态出发；接受的是细步结果，无 Richardson 外推。误差超过 1 会拒绝试算；达到最小步长仍失败时停止并保留之前接受的状态。

修复制冷站已有误差估计的量纲错误：Newton 使用归一化状态向量，而局部误差原先直接对该向量应用 kg/J/K 容差。现在先恢复物理量。对应的第一步可能比过去短，这是实际执行原有物理容差所必需；不能沿用旧的步数或速度结论。`local_error_norm_max` 只记录本帧已接受试算，拒绝计数另行记录。

固定步流体帧保留实际步长、接受步数、累计步数和求解重试信息；不重复保存四项不适用的自适应零值（本帧误差拒绝、累计误差拒绝、边界截断、局部误差范数）。步统计随物理状态原子接受，最后接受帧与发布帧一致。原有 2001 帧趋势历史小于 3 MB 的门禁和失败后能量不推进的门禁均保持通过。

## 校核

`tests/test_timestep_domains.py` 覆盖水箱热响应相对细步参考、封闭风侧房间水分精确累计、冷库双热容矩阵指数解、最小步长失败的库存/控制回滚、储热联算的 J 量纲、schema 5 作者压缩机与原生水侧联算的单次提交及失败回滚，以及三种执行域断点续算的一致性。

旧 `test_timestep.py`、`test_timestep_station.py`、`test_timestep_transactions.py`、`test_session_checkpoints.py` 与冷库 A、风侧房间、前向物理测试继续作为回归门禁。具体本轮测试数量由总验收记录汇总。

## 仍有明确能力边界

- 普通流体/风水中的 Python 作者模块尚未实现整步、半步之间的作者状态事务重放，因此开启自适应时明确返回 `TIMESTEP_AUTHOR_STATE_UNSUPPORTED`，仍可用固定步运行。不能只比较原生库存而宣称覆盖了任意作者动态状态。
- 制冷侧 schema 5 本构作者可以与原生单相液体侧联算；同一耦合会话同时配置液体作者和制冷作者时返回 `COUPLED_AUTHOR_ADAPTER_CONFLICT`，因为两个适配器尚未合并成统一事务。
- 相态明确的液体阀、气体压缩机仍检查端口相别；取口露出液面时不得自动把液体设备变成气体设备。任意流型切换和跨相通用管网需要另行定义设备合同。原有液位上下限与日程/控制时钟边界仍有效。
- 自适应控制的是局部时间离散误差，不是设备标定误差，也不将当前均相两相模型升级为分相流动模型。
