# 工作台：从组网到查看结果

更新日期：2026-11-12。工作台保留常用操作按钮，正常状态不再显示五步条或教学说明。顶部仅在待应用修改、运行失败、连接中断或结果过期时显示简短提醒。启动与三个代表工程的完整操作见[设备组网与运行仿真使用步骤](CORE_WORKFLOW_GUIDE.md)，已验收范围见[交付记录](CORE_WORKFLOW_ACCEPTANCE.md)。

## 第一次使用

1. 在“项目”页打开已有项目，或点击“新建项目”。可以选泵阀并联管网熟悉操作，也可以从空白画布开始。
2. 空白项目会展开左侧“设备库”。选择设备后点击画布放置；也可以拖入设备。设备库收起时，用上方“设备库”或空画布的“添加第一台设备”打开。
3. 点击“连接端口”，依次点选两个空闲端口；按 Esc 取消未完成的连线。双击设备填写参数。
4. 点击带文字的“检查连接”。检查结果会区分错误与警告；处理错误后重新检查。通过后点击“返回工作台”，再开始运行。
5. 画布右侧“运行”开始计算；“暂停”后可“继续”或“单步”，停止后可修改连接等结构。用“运行设置”打开求解设置，选择稳态/动态、仿真时长、输出间隔，以及按真实时间或快速计算；详见[运行推进与实时读数](RUNTIME_FEEDBACK.md)。
6. 双击设备调整参数，再点击“预览并应用”并确认差异。关闭窗口后，顶部仍会提示待应用修改；点击“查看修改”可返回相应设备，多台设备有修改时会先列出清单。
7. 用“曲线”展开同屏观察，也可以从左侧进入完整曲线页。参数变更后，旧结果会标为待重新采样；再运行或单步取得新结果。
8. 点击右上角“保存工作区”，保存全部项目与编辑草稿。保存不会使未应用参数自动生效。

## 状态与处理方式

| 顶部提示 | 含义与下一步 |
| --- | --- |
| 修改尚未应用 | 计算仍使用已应用设置；“查看修改”返回草稿，不会直接提交 |
| 结果已过期 | 保留结果对应旧设置，需要重新采样 |
| 本次运行失败 | 查看诊断；若尚未生成结果，则回退显示实际失败事件 |
| 连接中断，正在重连 | 保留最近结果，重连前无法确认运行状态和命令回执 |

暂停保留运行状态，并不解除结构编辑限制。连接、工况等结构调整仍需停止运行。PID 或脚本接管的参数遵守设备面板的提示，控制页区分项目初始配置、已确认修改与实际采样；采样不会自动覆盖项目默认设置。

曲线页选择历史记录时保留该记录的项目、参数和变量绑定。应用新参数后，旧结果标为待重新采样；连接中断时保留最近结果，但无法据此确认后台仍在运行。只有记录带有完整快照且支持“从快照续算”，才能延续接受状态；普通保存重开后重新运行使用项目初态。

## 界面调整

- 2026-11-12：设备、模块、项目、设置、控制、结果及辅助弹窗统一清理常驻教学文字；模型与验证详情集中到主动打开的说明中。范围与检查见[界面说明清理](INTERFACE_COPY_CLEANUP.md)。
- 去掉常驻步骤条、正常态操作建议和重复说明，仅保留需要处理的短提醒。
- 运行、暂停、单步、停止、曲线和运行设置位于画布右侧；参数浮窗的打开、拖动和最大化会避开右侧操作栏。
- “设备库”“连接端口”“检查连接”使用文字入口，工况和扩展操作放在次一级工具栏。
- 新建普通空白项目也会恢复设备库，空态按钮可直接打开并聚焦设备搜索。
- 增加当前项目待应用修改清单，可跨画布返回设备；继续使用原有预览与应用事务。
- 预检摘要、未采样曲线、运行失败和断连提示与真实状态对应；设备窗口和顶栏统一使用“保存工作区”。

本轮未修改物理算法、参数接受事务或持久化格式。浏览器检查使用独立临时工作区。
