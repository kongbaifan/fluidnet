# 热水锅炉与几何系数弯头

2026-11-05。新包 `hydronic_boiler` 和 `geometry_bend` 均为v1，不覆盖原加热器/管件。

锅炉：额定热量×供热比例进入液体，低位热值口径燃料输入=供热/效率，热损=燃料输入−供热。热量进入流体用thermal回调，热/燃料累计只在接受步增加。最小流量和出水温度在最终观察检查；请求正供热但未启用热联算时，以 `BOILER_HEAT_NOT_SOLVED` 拒绝，停炉或零负荷允许只求水力并保持通流阻力。没有锅炉本体储热、燃烧/烟气组分、冷凝回收、启动损失。字段、运行可写权限见manifest。不是厂家锅炉仿真。

圆弯头：K=用户给定R/D系数表×角度倍率表，使用本模块口径平均速度，Δp=Kρv|v|/2。曲线线性插值，不许外推；用户声明最大适用速度。默认系数是明确教学假设，不冒充Idelchik/厂家关联式，不自行推断Re或粗糙度修正；圆管、水/气单相，湿空气透传按声明。此完成的是可配置几何系数模型，矩形变径、导流叶片、全Re关联式仍需来源数据及新验证。

依据：Modelica.Fluid.Dissipation关于曲弯压损说明区分总压损、摩擦和局部项，并明确Re/几何范围；本首版只实现用户提供局部K表。表来源须填写data_source，不能把其默认值当成标准设计值。

测试 `tests/test_boiler_and_bend.py` 最终19项通过（19.75s）：流体焓升、供热/燃料/热损独立账、低流量拒绝、停机通流、累计能量、几何插值与独立局部压降、种子生成一致性、干/湿空气正反流、含湿量透传、禁止系数外推、关闭热联算的运行/停机分支与超温失败不累计。两份示例 `examples/hvac-expansion/hydronic_boiler.project.json`、`geometry_bend.project.json` 及同名recipe可按三设备两连接从空白组装；锅炉最终还验证了保存重载后从运行档案下载HTML/CSV，证据登记于整体实施记录。
