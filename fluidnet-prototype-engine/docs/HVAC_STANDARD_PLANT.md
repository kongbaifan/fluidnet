# 标准机房基础案例：运行、调阀与复算

更新日期：2026-11-02。示例 ID：`hvac-basic-plant`；界面名称：**暖通基础 · 双盘管冷水机房**。

这个案例用于验证机房组网、水量分配和热平衡。先用现有设备把完整流程跑通，后续按案例实际需要增加工程细节。设备尺寸、曲线和负荷为可复现的教学假设。

## 1. 案例包含什么

| 回路 | 主要设备与连接 |
| --- | --- |
| 空气 | 新风／回风混合、过滤、两台串联水盘管、送风机、房间、回风与排风 |
| 冷冻水 | 冷冻水泵 → 冷水机组 → 过滤器 → 异径管 → 关断阀 → 分水器 → 两条“平衡阀 + 盘管”并联支路 → 集水器 → 泵入口 |
| 冷却水 | 冷却水泵 → 冷水机组冷凝侧 → 冷却塔 → 泵入口 |

两台盘管在**水侧并联、风侧串联**，服务同一个房间。两个水回路分别有压力参考，参考口在接受结果中没有补水流量或热量输入。

## 2. 从界面运行

1. 启动服务，进入左侧“风系统”，点击“创建风侧示例”，选择“双盘管冷水机房”并创建项目。
2. 点击“湿空气设置”，把“运行模式”设为“稳态”，点击“应用设置”，再点“运行计算”。
3. 在“风量与状态”中查看空气与液体回路；进入左侧“控制”，查看四个仪表：供回水压差、两支路体积流量、第二盘管水侧热功率。
4. 回到“风系统”可导出 HTML 报告和 CSV，报告中的仪表使用同一次运行的结果。

本机基准结果（平衡阀 1 为 80%，平衡阀 2 为 100%）：

| 读数 | 结果约值 |
| --- | --- |
| 支路 1 水量 | 3.417 m³/h |
| 支路 2 水量 | 4.427 m³/h |
| 分集水器压差 | 14.670 kPa |
| 第二盘管水侧热功率 | 4.662 kW |
| 机组制冷量 | 14.120 kW |
| 冷却塔排热 | 15.819 kW |
| 冷冻水供水温度 | 7.0 °C |

## 3. 调阀并保存复算

1. 点击“编辑拓扑”，再点工具栏“适应画布”，即可看到包含 30 个设备的完整画布。
2. 双击 `Balance1`，把开度由 **80% 改为 40%**，点击“应用”并确认，再关闭设备窗口。
3. 回到“风系统”。页面应提示旧结果已过期；重新“运行计算”后，支路 1 水量下降，支路 2 水量增加。水量由真实网络重新求解。
4. 点击“保存项目”，刷新页面后再次运行。四个仪表的数值应与刷新前的 40% 工况一致，两个水回路及阀门参数应保留。

| 读数 | 80% 基准 | 调到 40% | 保存重载后 |
| --- | --- | --- | --- |
| 支路 1 水量 / m³/h | 3.417 | 1.679 | 1.679 |
| 支路 2 水量 / m³/h | 4.427 | 5.410 | 5.410 |
| 分集水器压差 / kPa | 14.670 | 21.902 | 21.902 |
| 第二盘管热功率 / kW | 4.662 | 5.517 | 5.517 |

## 4. 验收标准与证据

`tests/browser-hvac-plant.mjs` 从界面创建项目、运行、调阀、导出报告、保存和重载后复算。基准、40% 调阀和重载三个结果都检查以下关系：

- 分水器总质量流量等于两台盘管水流量之和，误差小于 `1e-7 kg/s`。
- 用盘管端口的质量流量和进出口比焓独立计算吸热量；机组冷量等于两台盘管吸热量加冷冻水泵轴功，误差小于 `0.05 W`。
- 冷却塔排热等于机组冷凝热加冷却水泵轴功，误差小于 `0.05 W`。
- 仪表流量与质量流量／密度一致，第二盘管热功率与独立水侧核算一致。
- 两个压力参考口流量小于 `1e-8 kg/s`，参考口输入热量为零。
- 保存重载后四个仪表复算一致，页面没有未捕获的 JavaScript 错误。

本机实测三个结果的支路质量残差为零，两个水回路热平衡误差均小于 `0.006 W`；重载后四个仪表数值与重载前一致。

在项目目录执行：

```powershell
$env:PYTHONPATH='backend'
npm run test:browser:hvac
```

运行生成 `artifacts/hvac-plant-validation.json`（三个工况的数值与残差）、`hvac-plant.project.json`、`hvac-plant.prototype.json`、HTML／CSV 报告及 1080p 截图。脚本也接入全量 `test:browser`，由既有 CI 收集这些产物。完整暖通检查见[验收记录](HVAC_BASIC_EQUIPMENT_ACCEPTANCE.md)。

本例先验收稳态计算；泵切换、压差确认和联锁停机由 `hvac-plant-interlock` 及暖通专项测试单独覆盖。液体储热、厂家性能曲线和多机启停按具体需求另行推进。
