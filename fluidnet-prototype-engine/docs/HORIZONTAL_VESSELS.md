# 卧式圆筒制冷剂容器

日期：2026-11-05。新增 `horizontal_receiver`（卧式圆筒贮液器）与 `horizontal_drum`（卧式圆筒低压循环桶），采用水平圆柱截面的液位—体积关系。它们继续使用 `saturated_vessel` 的质量 M、内能 U 动态状态与现有子步接受事务，不引入第二套质量／能量积分器。

## 几何输入与端口

两个新模块均以 `diameter_m`（内径 D）和 `length_m`（直筒长度 L）作为独立输入，单位 m，最小值 0.01 m。总容积 `V = πD²L/4` 为派生量；不接受同时输入 `volume_m3` 或旧式 `height_m`，避免尺寸和容积不一致。

| 模块 | 默认尺寸与初态 | 端口 |
| --- | --- | --- |
| `horizontal_receiver` | D=1.2 m，L=3 m，35°C，液体体积分数 62% | `in0/in1` 进口，`liquid` 液相出口、`vapor` 气相出口；`in0/liquid` 必连 |
| `horizontal_drum` | D=1.4 m，L=3 m，−30°C，液体体积分数 40% | 同上；`in0/vapor` 必连，液相出口可接泵或满液蒸发器 |

工质来自项目或回路锚点，可用于 NH₃ 或适用温度范围内的 CO₂。默认温度不是强制设定压力；容器仍由 M/U/V 反求饱和压力，几何只决定容积和液位换算。初始化、运行液位区间及单相越界保护沿用现有饱和容器规则。

## 液位语义

**`level_ratio` 始终是液体体积分数，不是液位高度比例。** 初始值与 `min_level_ratio/max_level_ratio` 的意义保持原合同。液位高度 h 从筒体内底面量起，高度比例为 `h/D`。

| 输出键 | 含义 |
| --- | --- |
| `state.level_ratio` | 液体体积分数，0–1，显示为 % |
| `state.level_m` | 卧式圆筒真实液位高度 h，m |
| `state.level_height_ratio` | 液位高度占内径比例 h/D，0–1，显示为 % |
| `volume_m3` | 圆筒几何总容积，m³ |

圆截面半径 r=D/2，液位 h 对应的面积为：

```
A(h) = r² arccos((r−h)/r) − (r−h) √(2rh−h²)
liquid_volume_fraction = A(h) / (πr²)
```

因为圆筒长度恒定，截面面积比等于体积比。模型以单调反解得到 h/D；仅在半满时体积比和高度比同为 50%。高度为 25% 时体积约为 19.55%，因此直接把“体积液位百分比 × 直径”当作高度是不正确的。

纯几何函数在 `refrigeration/vessel_geometry.py`：`horizontal_volume`、`horizontal_volume_fraction`、`horizontal_height_ratio`。空、半满、全满端点精确返回 0、0.5、1；靠近空筒使用级数减少相减损失，上半筒使用对称性。极接近满筒时剩余弓形体积小于双精度分辨率，正算可能舍入到 1；正常模型运行液位区间默认 5%–95%，不在该极限内。

## 兼容与物理边界

原 `hp_receiver`、`lp_drum`、`pumped_drum` 及多进口版本保留 `volume_m3`／`height_m` 输入和线性高度换算，不自动升级或修改已保存定义。新几何输出只在卧式容器帧内提供，不增加旧容器结果键。编译参数验证对同一 `saturated_vessel` 求解模型优先使用相同模块 ID 的注册合同，避免将旧式容积／高度错误注入新模块；未注册别名继续保留原求解模型回退行为。

仅计算水平直圆筒，**忽略封头容积、倾斜、液面晃动、内部构件占容和静压分布**。没有据此增加两相管路压降或汽液分离效率模型。液位高度可供观察或控制输入，但原体积分数上、下限不会自动转成高度阈值；控制逻辑需要明确选择对应变量。
