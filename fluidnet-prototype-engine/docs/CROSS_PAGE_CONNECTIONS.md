# 多画布连接：建模、跳转与统一运行

更新日期：2026-11-02。实现基线：`9176529` + 本次跨页连接改动。

同一个项目可以拆到多张画布，画布之间的连接仍属于同一张网络。所有设备由同一次运行求解，使用同一时间轴；画布划分不会增加压力边界、复制设备或改变流量和热量关系。

## 1. 拆分已有系统

1. 在建模工具栏点击“新增画布”，例如创建“机房”“末端 1”“末端 2”。
2. 在原画布单击设备，点击选中设备工具栏的“移到其他画布”，选择目标画布并确认。
3. 已有连接与设备变量引用保留。跨页连接自动出现在两端画布上方的连接栏中；点击连接标记可跳转到另一端，并打开对应设备。

设备多时先点“适应画布”。每个项目仍最多八张画布，每页最多 64 台设备。

## 2. 新建、修改和断开跨页连接

- 点击建模工具栏“跨页连接”，进入项目连接列表，再点“新建跨页连接”，选择起点端口、目标画布和目标端口。
- 也可双击设备，在设备窗口的“连接”页签为未连接端口选择“跨页连接”。已连接端口会显示另一端的画布、设备和端口，并提供跳转、修改和断开操作。
- 修改连接时保留连接标识；新目标必须为空闲且类型兼容的端口。失败的修改不会覆盖原连接。
- 端口占用在整个项目中检查。任一端断开，另一端的连接标记同步消失；删除设备会清理所有画布上关联的连接。
- 普通端口连接操作也支持先选起点，再切换画布选择终点。

流体端口沿用原有连接规则；其他类型的端口还需满足输入／输出方向。工质声明与物理网络的完整校验由现有后端编译器执行。

## 3. 运行、保存与导入

切换画布和跨页跳转可在运行中进行，运行 ID 和时间轴保持不变。修改连接或移动设备时先停止运行；修改完成后重新计算。

“保存原型”“保存此项目”、刷新恢复和复制项目都会保留跨页连接。复制后的项目可以独立修改。

“导出此项目”的单项目格式保留页面名称、布局、草稿、模块快照和控制配置。“导出计算项目”的规范 Project JSON 保留设备的画布标识及跨页连接，导入后按画布标识分组显示。两种格式都能重新计算同一张网络。

导入规范计算项目后，在“设置 → 运行求解”选择运行模式和时长。内置设备参数面板使用导入文件的参数定义，修改开度等参数后可继续应用与复算。

替换同 ID 项目前，以单项目格式备份被替换项目及其模块、型号和曲线绑定，存放在浏览器的 `fluidnet-prototype-engine-v1-before-project`。其他项目的草稿继续保留在工作区中。

## 4. 验收案例

两支路管网按“主系统、末端 1、末端 2”拆页，保留四条跨页连接。浏览器验收覆盖移页、断开重连、修改、两端跳转、设备删除和撤销后复算、运行中切页、保存刷新、两种格式导入、复制项目及副本调阀。

标准机房按“原空气画布、末端、机房”拆页，保留四条跨页连接。原画布保留风系统与房间；末端页放两台盘管、平衡阀和分集水器；机房页放冷水机组、两台水泵、冷却塔和水侧辅助设备。

## 5. 数据与兼容

沿用 `pages[].edges` 的五项连接格式 `[连接ID, 起点设备, 起点端口, 终点设备, 终点端口]`，由起点所在画布存储一次。显示、占用校验、迁移和删除均按项目检索；跨页另一端从同一条连接派生。

后端原型归一化把各画布设备、连接汇入同一个 Project。规范项目导入按 `page_id` 分组设备，并把连接放入起点画布。旧单页项目和原有连接格式继续适用。
