# R05–R07：真实制冷剂流股、回热器与 DX 分支

日期：2026-11-05。本批新增显式单相焓流股与 DX 专用局部联立路径，旧饱和集总设备仍按原合同运行。

## R05 有焓流股

新增 `refrigerant_line`、`enthalpy_compressor`、`enthalpy_valve`。管段按单相物性逐段推进 Darcy 压降和环境 UA 热损；压缩机从实际入口 p/h 计算密度、质量流量、等熵焓升和功率；节流阀保留入口焓。流股必须串接到一个显式压缩机或阀桥，首版禁止分支、回环和共享管段；两相状态或相态转换进入单相管段直接报 `REFRIGERANT_LINE_PHASE`。

边界容器仍提供饱和相出口的初始 p/h，桥出口真实焓进入下游设备和容器 U 收支。单相流股无独立持液，使用范围是短串联设备/管段，不宣称通用制冷剂两相管网。旧 `refrigerant_compressor`、`expansion_valve` 和饱和设备不经过新路径。

## R06 过冷器与回热器

`refrigerant_subcooler` 是单流股外部冷源 UA 设备；`refrigerant_recuperator` 有 `hot_in/hot_out`、`cold_in/cold_out` 四个制冷剂端口，使用逆流 ε–NTU 联立两侧质量流量，热量等量反向。回热器无储量，入口/出口焓直接进入对应桥；压降首版为0。复用实际端口焓，不能只新增“过冷温度”显示值。

示例：

- `stream-line.recipe.json`：单库真实入口焓压缩机＋吸气管；
- `stream-subcooler.recipe.json`：真实吸气管＋外部过冷器＋有焓节流阀；
- `stream-recuperator.recipe.json`：热侧液流与冷侧吸气回热。

三者均是普通 `refrigeration` 执行域、无控制脚本；工质 R134a。管段热损、过冷 UA 与回热 UA 是教学输入，不是厂家标定。

## R07 DX 三模块设计

DX 路径包含 `dx_expansion_valve`、`dx_evaporator`、`dx_compressor`。高压贮液器液相经阀进入两区蒸发器：沸腾区吸热后，剩余 UA 加热气相，真实出口 p/h/温度/过热度直接给压缩机；压缩机用实际吸气密度和焓求排量质量流与功。蒸发压力由阀流量与压缩机容积流量局部联立求得，首版不增加低压储液器或冷媒管路储量。

DX 只接受有真实过热的气态出口；出口仍两相、低于最小过热或无合法蒸发工作点时拒绝。阀关闭与压缩机停机需同步，首版不模拟抽空、液击、启动惯性或结霜；不允许把泵供液 `air_cooler`、饱和压缩机或普通单相管段当作 DX 替代。

`dx.recipe.json/project.json` 为 6 设备/6 连接：高压容器液相→DX阀→DX蒸发器→DX压缩机→冷凝器→同一容器，DX蒸发器热口接库房。运行域为 `refrigeration`，专用局部路径不与旧泵供液或有焓单相链交叉串接。设计蒸发温度−25°C、过热3K、冷凝35°C、库温−18°C、净冷量5kW。阀开度从0.5降到0.4，实际过热约升到11K；0.6等过供工况若无满足最小过热的联合解则明确拒绝，绝不以饱和气代替两相出口继续算压缩功。

蒸发器总UA分为饱和沸腾所需 `m(h_g−h_in)/(T_room−T_sat)` 和剩余气相区，气相区以局部饱和气比热计算有效度，再由真实物性求出口焓；它是有明确分区假设的集总模型，不是分布参数两相流。库房和高压容器动态推进；低压分支不储冷媒，因此不模拟质量充注迁移、启动抽空及节流过供液积存。过热反馈由真实焓/温度产生，可用现有PID写阀开度；本例不自动添加控制，控制增益需单独验收。

流股和DX示例的局部压力、焓输出真实进入压缩功和容器内能账。回热器首版以入口热容率的逆流ε–NTU近似，焓增减严格等热，出口单相必须验证；不是厂家性能模型。单相流股停止时不通过无储量管段注入UA热，阀后出现两相不能连接单相管段。
