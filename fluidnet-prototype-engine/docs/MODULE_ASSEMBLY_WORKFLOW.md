# 做设备模块，再用模块搭建项目

这条流程围绕设备模块、画布连接、调参运行和保存复用展开。先用现有模板完成一个可运行的设备；搭建时缺少的设备记录下来，再按需求补充。

## 操作步骤

1. 在“模块”里选择“新建算法模块”，填写名称和唯一标识。默认从“两端口局部阻力”模板开始，也可以选择泵、换热器等模板或已有模块。
2. 编辑端口、参数和算法，点击“保存新版本”。系统校验并试算成功后，编辑器显示保存版本，并启用“放入项目”。创建请求失败时会保留输入，可以直接重试。
3. 在“项目”里创建空白项目。返回模块编辑器，点击“放入项目”，选择项目和画布，点击“添加设备”。设备会放入所选画布并打开参数窗口。
4. 在设备窗口的“连接”页签点击“连接设备”，选择目标画布和端口。同页和跨页都支持；列表排除本设备、已占用和类型不兼容的端口。没有可用端口时，先添加另一台设备。
5. 修改参数并确认应用，连接完整后运行，查看设备结果和曲线。修改参数后可以重新运行，比较变化。
6. 点击“保存原型”保存项目。再次搭建时，从模块编辑器选择另一个项目，即可复用已保存的设备模块。

## 版本如何使用

- 未保存过版本的 Python 模块需要先保存，才能放入项目。插入失败时保留当前页面，不生成项目模块快照。
- 修改模块草稿不会修改项目中的已保存算法和参数定义。“放入项目”明确显示本次使用的版本。
- 已有项目继续使用其固定版本。例如模块库已保存 v2，而项目固定 v1，新增同类设备仍使用 v1；需要更新时，在项目的“模块版本”中统一升级。
- 目标项目正在运行或暂停、目标画布已有 64 台设备时，会提示先停止运行或换一张画布。

## 设备编辑器的常用入口

- **设备与端口**：新建模块后先进入这里。可以编辑设备名称、用途说明、图形及端口名称，再切换到常用参数。
- **常用参数**：参数表显示名称、显示单位下的默认值和范围。Python 模块点击“编辑”即可修改；新增参数支持数值、是／否和文本。泵模板的扬程曲线支持点表编辑和预览，其他曲线继续通过完整定义编辑。
- **单位换算**：选择 `%`、`mm`、`kPa`、`°C` 等显示单位时，已填写的默认值和范围一起换算。例如 `75%` 保存为 `0.75`，`40 mm` 保存为 `0.04 m`，`25°C` 保存为 `298.15 K`。已有单位只提供相同物理维度的常用选项；自定义换算继续保留。
- **内置设备**：常用参数页展示默认值和范围，可直接放入项目调参，并将常用参数组合保存为型号。
- **算法与高级设置**：算法保留独立页签。契约 JSON 放在高级设置里，输出变量和完整参数定义默认折叠。算法页的测试工具默认折叠，有错误时展开；版本保存结果也会显示在普通编辑页。

修改默认值只更新当前模块草稿，已有项目仍使用固定版本。修改一个常用参数时，其余参数的库值保留；修改设备名称和说明也会保留库值。

常用编辑验收：`npm run test:browser:module-editor-simple`。覆盖泵、阀、换热器的入口检查，以及新模块的名称、端口、参数换算、失败提示、版本保存、项目应用与刷新恢复；结果写入 `artifacts/module-editor-simple/`。

## 本轮验证

浏览器验收通过界面创建模块、保存版本、选择空白项目及画布、连接设备、调整参数、运行、保存并刷新，最后在新项目中复用。没有直接写入应用状态来构造工程。

实例采用两端压力 250 / 120 kPa、直径 0.04 m、阻力系数 12。计算流量为 5.8442806899 kg/s，与独立局部阻力公式一致；阻力系数改为 48 后流量为 2.9221403450 kg/s。保存、刷新后重新运行得到相同结果。

验收同时覆盖创建失败重试、重复提交拦截、关闭后到达的创建响应、单张画布连接入口、端口占用过滤、旧项目固定 v1、新项目采用 v2，以及未保存草稿保留。

运行命令：`npm run test:browser:module-assembly`。结果和截图写入 `artifacts/module-assembly/`；跨页连接及导入导出回归使用 `npm run test:browser:cross-page`。
