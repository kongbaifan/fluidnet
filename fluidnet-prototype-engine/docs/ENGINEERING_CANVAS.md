# 工程画布：图形、真实结果与交互

日期：2026-11-06。基于现有 SVG/原生 JavaScript 工作台，完成设备图形与作者布局贯通、真实结果图层、设备实体避障、拖动增量更新及独立前端模块。培训剧本、故障注入界面和评分不在本轮范围。

## 入口与操作

建模页新增“工程画布显示”工具条，可选择工质回路、质量流量、温度、绝对压力，打开数值标签，设置色标范围或关闭流动动画。“运行告警”查看当前运行的警告/错误；有真实设备归属时可定位到对应画布和设备。

设备图形按模块类型提供可区分的线条符号：压缩机、冷凝器、冷风机、风机、泵、阀、卧/立容器、房间、换热器、热泵、机组、设备组等。未知模块显示简称。它们用于识别设备族，不宣称满足某项工程制图标准。

“模块开发 → 图形与端口”设置的形状、宽高、标签和端口坐标进入新插入实例的项目快照。主画布与编辑器采用相同坐标关系，旋转同时作用于图形和接线。重复/过近端口在显示层分散，源端口定义不改；密集端口的命中半径随实际间距调整。修改模块库绘图不会改写已冻结项目。普通模块升级保留原有升级流程，未新增跨版本布局迁移功能。

## 结果语义

| 显示 | 数据依据与边界 |
| --- | --- |
| 工质回路色 | 来自最近成功的回路检查，不代表温度或流向 |
| 流量色和线宽 | 已接受帧的实际质量流量幅值，默认 0–5 kg/s；标签保留相对连接源→目标的正负号 |
| 温度 | 真实端点温度 K→°C；有流向时优先上游端点，不能当作整根线的平均温度；默认 −30–80°C |
| 压力 | 真实端点绝对压力 Pa→kPa(abs)，默认 0–1000 kPa(abs)；不是表压 |
| 箭头与动画 | 后端端口以流入设备为正，沿连接源→目标的流量据此转换；零流不画方向，缺失或两端矛盾不推断方向 |
| 设备状态 | 真实声明的运行状态输出、已知融霜/滴水状态或关联诊断；不从开关设定值猜测设备已运行 |
| 告警 | 同一运行的已接受帧及终态失败诊断，重复项合并；没有设备ID的系统错误只展示，不伪造定位 |

色标范围仅控制显示，越界使用端点色，读数不截断。灰色/“—”表示未知。没有逐口流股输出的集总制冷设备不能借用整台设备总流量给所有端口画箭头；热连接尚无统一逐口热流符号合同，本轮不推断热流方向。

只有运行中的有效完整采样启用动画。暂停、完成、失败、趋势抽稀帧都停止动画；趋势期间显示最近完整关键帧并注明采样时刻。参数或拓扑已变更时停用物理着色和流向，提示结果过期。初始化失败没有有效帧时只显示诊断，不把失败试算值当作物理结果。

## 几何与更新方式

正交路由优先尝试直接和折线路径，必要时用有预算的搜索避开设备实体。端口短引线按设备旋转后的朝外方向离开。无法避让时保留连线、显示“避让未完成”，不改变物理连接。首版只保证对设备实体的几何检查，不承诺标签避让、跨页线路绘制、连线间零交叉或全局最优布线。

路由按页面几何内容缓存。拖动节点的更新合并到浏览器绘制帧，只改节点变换及关联连线；松开后统一重算本页路由，修复对其他连线的新遮挡。实时结果刷新只更新边结果和节点状态，不重建全部设备。前端仍为每页64台、每项目8页，未因本轮改动扩大容量。

## 职责拆分

| 文件 | 职责 |
| --- | --- |
| `canvas-symbols.js` | 设备族图形、作者布局、旋转边界、密集端口和展示快照复制 |
| `canvas-routing.js` | 有界正交避障，纯几何输入输出 |
| `canvas-observations.js` | 规范帧、实际端口流量、状态与诊断的只读适配 |
| `canvas-view.js` | SVG渲染、路由缓存、节点及边的增量更新 |
| `canvas-workspace.js` | 显示工具条、色标、帧归属、过期判断和告警定位 |

这些模块不提交引擎参数，不建立第二份拓扑，不改变物理模块版本或双哈希。继续使用现有依赖注入和脚本加载机制，未引入第三方画布框架、bundler、Canvas或WebGL。

同时修复旧示例的参数冻结顺序：目录暴露新增数字参数后先补默认值，再冻结展示快照；各快照的旧显示参数定义独立保留，避免规范项目导入时与旧字段混用。结果有效性按项目绑定模块及物理端口识别，改变位置或作者图形不再误判为物理结果变化。

## 定向验证

入口：`npm run test:ui:canvas`、`npm run test:browser:canvas`。按用户要求没有运行全量测试或完整浏览器链。

最终定向前端单测84项通过，覆盖新画布、相关项目状态/帧归属、参数应用和旧字段迁移。3个新浏览器脚本及3个既有相关回归分别执行通过；JS语法及差异格式检查通过。

- 图形与几何单测覆盖设备族区分、作者宽高/端口、重叠端口、旋转、快照隔离和文本转义；路由覆盖实体绕行、同侧/旋转端口、预算耗尽与明确回退。
- 观测与工作台单测覆盖实际正负流、零流、未知、多通路、矛盾端口、单位、色标越界、过期/趋势/暂停、诊断归属及失败无有效帧。
- `browser-canvas-symbols.mjs`：真实UI编辑→发布→插入→旋转→修改库草稿→单项目导出/导入→刷新，图形快照与接线端点保持一致；冷库8设备图形可区分。
- `browser-engineering-canvas.mjs`：真实后端求解、正流、反转边存储顺序、关阀零流、温压图层、色标与动画、结果过期、重载、合法历史模块警告定位和真实初始化失败告警。
- 原 `browser-smoke.mjs`、`browser-path-trace.mjs`、`browser-open-refrigeration-groups.mjs` 回归通过，分别覆盖调参真实结果、跨页/双侧通路、密集公开端口组装与重载。

本地证据在 `artifacts/engineering-canvas-evidence.json`、`canvas-symbols-ui.json` 和同目录1080p截图。运行显示详见 [专项UI验收](ENGINEERING_CANVAS_UI_ACCEPTANCE.md)，性能测量见 [画布交互性能](CANVAS_INTERACTION_PERFORMANCE.md)。

本轮真实负压差初始化测试遇到既有 `HYDRAULIC_NOT_CONVERGED / gtol`，记录于 `artifacts/canvas-existing-boundary.json`；未修改求解器。浏览器反向箭头验证采用反转连接存储方向，单元测试另外覆盖实际负端口流量；不把它写成负压差求解问题已解决。
