# S5/S6 物理设计卡

2026-11-06。新增模型保持旧模块ID/版本与schema解释。所有存量仍由现有StationSession的M/U与统一接受事务管理。

- `headed_receiver`：水平直筒＋两半球封头；D和直筒L独立，V=πD²L/4+πD³/6。液位体积为圆弓筒段加球冠，单调反解。新增tap0..2高度比例；端口静压按浸没液柱。取口可连接既有压缩/阀角色，所需相态不满足时拒绝，禁止将液体送压缩机。潜能/液面晃动/非平衡界面不建模，原liquid/vapor保留底/顶相口。
- `room_heat_manifold`：8个可选热输入＋1个必连输出；可级联，拓扑必须是有根无环树，最终只连接一个库房。自身无热容，叶冷风机净热量只加一次；不复制库房物理状态。
- `immersed_tube_bundle`＋显式壳体：复用饱和容器M/U＋独立显式单相管束通路；有限UA由实际流量热容率得到效能，流股焓变化等量反向进入容器。管程无持液，壳体有冷媒库存。相态变化只允许壳侧；管程相变拒绝。盘管式中冷复用同一核心。
- 耦合储热：以闭式缓冲箱固定Mh显热状态作为额外联立未知量，沿用已有状态向量接受/缩步机制；禁止用Python累计伪造库存。新能力显式选择，旧2关系同容器路径保持。
- 制冷组合：新增独立SDK能力，受限完整闭合单一工质内置制冷/热口组可展开；不让旧composite.v1变成任意跨域模块。子版本、输出/参数映射和状态隔离按原组合规则。

验证采用解析几何积分、独立质量/焓账、实际网络、失败回滚、冻结项目重载；不运行全量测试。示例系数为开发假设，不声称倍思鹿数值等价。
