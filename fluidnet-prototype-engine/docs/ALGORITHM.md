# 算法设计与实现边界

## 当前实现：稳态水力

输入为经过类型校验的 Project。所有计算使用绝对 Pa、kg/s、m，液态水密度固定 998.2 kg/m³，动力黏度固定 1.002e-3 Pa·s。给定温度只作为边界资料，不改变水力物性。

编译顺序：

1. 合并模块目录默认值与实例已应用参数，按注册模型校验数值和范围。
2. 检查流体领域、必需端口、重复连接、通路与端口覆盖；未知算法不得退化成默认阻力。
3. 用并查集合并外部连接端口，以及 junction 的内部端口，形成等压节点。
4. 将 enabled 通路转换成有向支路；source 转换成固定绝对压力。
5. 检查同一节点的边界压力冲突，拒绝支路短接。
6. 按非关闭支路划分子网络，每个子网络必须有压力参考。关闭阀门两侧的压力也必须可以确定。

每个自由压力节点有一个压力未知量，每条支路有一个质量流量未知量。方向由通路 input_port → output_port 定义。

```text
支路： p_start - p_end - Δp(m) = 0
节点： Σ流入 m - Σ流出 m = 0
边界： p = p_boundary
```

节点守恒不施加于给定压力节点；边界自动提供或吸收净流量。in/out 仅为端口的标称方向，不阻止反向流。

## 支路关系

### 阀门

```text
Kv_eff = Kv × opening_ratio
Q = m / ρ × 3600                      [m³/h]
Δp = 100000 × (ρ/1000) × Q|Q| / Kv_eff²
```

开度与有效 Kv 暂按线性关系，不声称已实现等百分比阀特性。开度为零时改用 `m = 0`，不设置隐含泄漏量。

### 管道

```text
A = πD²/4
v = m/(ρA)
Re = |m|D/(μA)
Δp = f × L/D × m|m|/(2ρA²)
```

Re ≤ 2300 使用层流式 `Δp = 32μLm/(ρAD²)`；Re ≥ 4000 使用 Haaland 近似：

```text
f = [-1.8 log10((ε/D/3.7)^1.11 + 6.9/Re)]^-2
```

过渡区域对两种压降线性插值。这是明确的工程近似；暂不含高程项、入口损失、传热或可压缩性。粗糙度实际参与计算，相对粗糙度限定不大于 0.05。

### 泵

曲线点为 `[Q_m3_h, H_m]`，要求从零流量开始、流量严格递增、扬程严格递减、末点扬程为零。区间内线性插值。

```text
H(Q,s) = s² × H_nominal(Q/s)
Δp = -ρgH
P_shaft = (-Δp) × (m/ρ) / efficiency_ratio
```

数值迭代可暂时线性延拓以定位根，但最终工作点超出有效曲线范围即失败。反向流和零转速模型尚未定义，不返回伪造结果。

目录示例曲线为 `[[0,20],[10,18],[20,12],[30,0]]`。它用于内置算例联调，不是实际设备的试验曲线；真实工程应提交设备自身的 head_curve。

### 双侧换热器

ch0 与 ch1 分别使用各自的节点和流量，当前共用定义中的 K 和等效直径：

```text
Δp_side = K × m_side|m_side| / (2ρA²)
```

UA 只保存，不改变当前水力结果。结果返回 THERMAL_NOT_SOLVED，热侧与冷侧的流量不会互相覆盖，也不会凭空产生出口温度。

## 求解与验收

使用 SciPy `least_squares`，压力变量与支路压力残差按 100000 Pa 缩放；节点质量残差按 1 kg/s 缩放，显式指定 `x_scale='jac'`。库的优化终止不等于物理合格，最终分别检查：

- 最大支路压力残差 ≤ pressure_tolerance_pa。
- 最大自由节点质量残差以及关阀流量误差 ≤ mass_tolerance_kg_s。
- 所有未知量有限，所有绝对压力为正，泵工作点在定义域内。

记录 `pressure_residual_pa`、`mass_residual_kg_s`、`iterations`（函数评估次数）、节点数和支路数。当前使用稠密数值 Jacobian，目标是小型原型网络；尚未完成大规模网络性能验证。后续可增加稀疏 Jacobian、连通分块和上一时刻解的初值。

## 当前准稳态序列

POST /runs 的 dynamic 模式产生 `0, dt, 2dt, …, duration` 序列，最后一个时刻准确截到 duration，最多 2001 帧。当前请求不包含随时间变化的边界和参数，所以求解一次后复用该稳态解，返回 DYNAMIC_QUASI_STEADY。

前端运行按钮提交计算，再回放已完成的帧。暂停、继续和停止只作用于回放。单步会对当前已应用参数重新求解，生成一个新的运行 ID，并在前端保留连续观察的历史。它不代表求解水箱液位、热惯性或流体动量的瞬态方程。

## 后续热力与状态算法定义（未实现）

热力层根据已收敛的流量确定上游，节点按焓流混合。在常比热近似下：

```text
T_mix = Σ(m_in × T_in) / Σm_in
```

零流量节点必须单独处理，不能除以零。换热器可采用逆流 ε–NTU 模型：

```text
C_h = |m_h| cp_h; C_c = |m_c| cp_c
C_min = min(C_h,C_c); C_r = C_min/C_max; NTU = UA/C_min
ε = (1-exp(-NTU(1-C_r))) / (1-C_r exp(-NTU(1-C_r)))
C_r = 1 时：ε = NTU/(1+NTU)
Q_heat = ε C_min (T_h,in - T_c,in)
```

任一侧无流量时热量传递模型需明确零流量极限；换向后重新映射入口。两侧能量残差必须相等且相反。

水箱建议以质量 M 和总内能 U 为状态，定密度、完全混合近似下：

```text
dM/dt = Σm_in - Σm_out
U ≈ M cp T
dU/dt = Σ(m_in cp T_in) - Σ(m_out cp T) + Q_heater - UA_loss(T-T_ambient)
level = M/(ρA)
p_bottom = p_surface + ρg level
```

状态推进采用隐式 Euler 或 BDF；每一步用状态给出边界，求水力及热力代数方程，再更新状态，失败时回滚并缩步。液位上下限作为事件处理。

控制器只允许写模块声明的 runtime 参数，建议定义采样周期、设定值、限幅、积分抗饱和及离散更新顺序。控制写入发生在明确时间边界，进入下一次代数求解，不能直接篡改已发布的历史帧。

这些状态方程为下一阶段设计，不在 v0.1 的通过测试能力中。Python 模块已接入独立 Worker；单相水/空气物性服务可用，完整可压缩气体网络、混合物、相变和水锤仍需另行设计。
