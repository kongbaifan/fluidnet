# 画布通路追踪

2026-11-05。入口为工作台上的设备端口：鼠标悬停或键盘聚焦端口，会显示当前设备内与该端口相连的已启用通路，以及通路各端口的实际外部连接。与其相邻的连线、远端端口同步高亮；跨画布连接在顶部条目高亮，提示卡列出目标画布、实例和端口，点击即可定位。

## 语义

追踪读取项目实例绑定的模块定义；存在冻结manifest时，通路以manifest为准。只按明确声明的通路端点相连，不根据设备外形、端口数量或相同工质推断内部连通。双侧换热器的两条通路互相隔离；禁用或端点失效的通路不参与高亮。没有内部通路定义的容器、节点或组合，只显示选中端口的实际连接。

提示卡标明“当前设备通路及相邻连接”，不递归穿越相邻设备，也不表示实际运行流向。鼠标悬停设备主体时分别显示各条通路，不暗示这些通路彼此连通。点击端口的原有接线行为保持不变；移动到提示卡可操作目标导航，按Esc或卡片关闭按钮取消追踪。

实现分为纯读取模块`frontend/path-trace.js`、展示样式`frontend/path-trace.css`和工作台原有inspection入口。追踪不修改项目参数、模块版本、连接或运行状态，不触发后端求解。
