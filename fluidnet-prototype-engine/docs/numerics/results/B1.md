## 2. 计数口径

- `nodes` / `branches`：来自 `CompiledNetwork.node_keys` 与 `CompiledNetwork.branches`，是编译后的实际拓扑。
- `hydraulic_unknowns`（稳态）= 支路流量 + 未定压节点压力；`hydraulic_unknowns_dynamic` 再加每个水箱的净流入未知量。
- `dependency_edges` = 连接边 + 每实例端口两两依赖（`C(k,2)`，k 为该实例端口数）；用于 D 分块/依赖排序的分母。
- `independent_loops` = 支路图 `E − V + C`；`graph_components` 由支路图并查集统计。
- `python_instances` = 运行时为 `python` 的实例数（每个实例会启动独立 Worker）。

历史口径核对：原计划 §2 记录的“100 实例、195 未知量”在本工厂 `series/small` 上复现为
`branches=98 + unknown_pressures=97 = 195`。

## 6. 偏差与未覆盖

- `python-multiport` 大档 48 个实例会启动 48 个 Worker 进程，单次求解约数十秒（实测小/中档 1.85 s / 2.11 s）；
  B1 测试只对全部档位做编译计数，不求解大档，避免拖慢常规测试。
- `mesh` 的边界只放两个压力参考；更复杂的多入口/多出口工况留给 B2 验收场景。
- 本包不涉及任何求解器默认值变更，不构成性能结论。
