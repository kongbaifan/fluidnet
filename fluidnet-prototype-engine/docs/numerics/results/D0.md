## 1. 实现

纯函数 `build_blocks(network) -> PartitionPlan`，不求解、不修改网络：

- `Block`：`nodes` / `branches` / `open_branches` / `fixed_nodes` / `tank_nodes` /
  `unknowns_steady` / `unknowns_dynamic` / `circuits` / `instances` / `reason` / `notes`。
- `BlockDependency(source, target, kind, detail)`：目前 `kind='thermal'`（换热器两侧）。
- `PartitionPlan`：块列表、依赖边、`degraded`、`reason`、`node_block[]`、`branch_block[]`、
  签名；`to_json()` 可直接导出（`json.dumps` 实测可用）。
- `plan_signature(network)`：结构 + 静态闭合状态 + Python 端口关系的 SHA-256；
  `resolve_plan(network)` 按签名缓存（上限 64 条，`clear_plan_cache()` 供测试清理）。

### 分块规则

| 对象 | 处理 | 依据 |
| --- | --- | --- |
| 非关闭支路 | `union(start, end)` | 传递压力耦合，必须同块 |
| 编译期关闭支路（`branch.closed`） | 不 union，只贡献「流量=0」 | 零流量约束不传压力；块内子网络不包含它，合并时写 `flow=0` |
| 压力边界节点（`fixed_pressures`） | 作为块内边界，不跨块耦合 | 边界压力已知 |
| 水箱节点（`storage`） | 稳态为固定压力、动态为块内未知净流入；不跨块切分 | 任何开放支路都把水箱节点与相邻节点 union |
| Python 实例 | 全部端口所属节点无条件同块 | 运行期关系可能是关闭阀/强制流量压缩机，保守处理 |
| 内置换热器 `heat_exchanger` | 两侧各自成块，块间加 `thermal` 依赖边，块说明写「水力独立、热力耦合」 | 水力通道独立、热力耦合 |
| 未知/无法证明 | 降级整网一块（`degraded=True`） | 见 §3 |

关闭支路归属其 `start_node` 所在块；若两端本就在不同块（关闭阀隔开的两个回路），
对侧块不需要这条支路的平衡行（流量恒 0），因此不会重复计数。

## 3. 降级条件（保守整网一块）

出现下列任一情况时 `degraded=True`、只有 1 块，`solve_hydraulics_hook` 立即返回 `None`，
继续常规全网求解（不改变结果、不冒错误拆分的风险）：

- `NODE_COMPONENT_UNKNOWN`：编译期 `node_component` 缺失/长度不符；
- `BRANCH_MODEL_UNKNOWN`：支路 `solver_model` 不在 `{pipe, valve, pump_curve, resistance, heat_exchanger}`；
- `INSTANCE_UNKNOWN` / `MODULE_UNKNOWN`：支路实例或模块定义缺失；
- `BRANCH_NODE_RANGE`：支路端点越界；
- `PYTHON_PORT_UNKNOWN`：Python 实例的声明端口没有节点映射；
- `CROSS_CIRCUIT_BLOCK`：多工质网络（`mixed=True`）中同一块跨多个工质回路；
- `PRESSURE_REFERENCE_MISSING` / `PASSIVE_BLOCK_UNKNOWN_PRESSURE`：块没有可解压力参考；
- `BLOCK_INTEGRITY`：节点/支路没有恰好覆盖一次，或未知量计数与全网公式不一致。

降级实测（把一条支路的 `solver_model` 改成 `legacy_magic`）：

```text
degraded True  降级整网一块：未知依赖：BRANCH_MODEL_UNKNOWN：支路 0（L1:ch0）模型 legacy_magic 的耦合性质未知
blocks 1  nodes [0, 0, 0, 0]  branch_block [0, 0]
```

## 5. 已知限制

- 本包只做「静态可证明」的拆分：Python 支路一律按压耦合同块，因此 Python 阀门关闭后
  不会把块再拆小（块只会偏大，不会错拆）。
- 关闭支路在分块路径下流量精确为 `0.0`；常规路径给出的是 `≤ mass_tolerance` 的数值零
  （实测 `|q| ≤ 1e-8 kg/s`），两者在 3.1 差值门内，但不是逐位相等。
- 未引入线程池/多进程（X0 之前不做）；块按固定顺序串行求解。
- `degraded` 只影响是否走分块路径，不改变物理语义。
