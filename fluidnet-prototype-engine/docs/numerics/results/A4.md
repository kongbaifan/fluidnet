| 行 | 内容 |
| --- | --- |
| 时间误差控制设置 | 开/关、质量/能量/温度 atol、rtol、内部步长上下限（全部来自项目快照） |

## 3. 保存/重启复算

- 模型层：把项目 JSON 保存后重新 `Project.model_validate` + `compile_project` 运行，接受步序列与末帧变量
  和原运行完全一致（`test_same_settings_reproduce_the_same_accepted_step_sequence`）。
- API 层：`create_app(data_root=tmp_path)` 结束进程后，用同一 data_root 重新创建 app，再提交同一项目 JSON；
  末帧 `variables` 与 `timestep_adaptive`/`internal_step_s`/`internal_steps_total`/`local_error_norm_max`
  完全一致（`test_saved_project_recomputes_after_app_restart`）。
- 注意：把**同一个已编译 network 对象**复用给两个会话不是受支持的复现方式；实测会因 network 内部缓存
  出现 1e-6 量级差异。复现的正确口径是“同一保存项目重新编译”（上述两条路径）。

## 4. 同参数重跑可复现接受步序列

B-S01、1200 s、动态步长 10 s、默认容差，两次独立运行 + 一次保存后复算：

| 指标 | 实测 |
| --- | --- |
| 接受步序列完全一致 | 是（3 次运行） |
| 序列 sha256 | `2442e5fad75f878976c03a039e1bbb78739edece225847d23f69d5c16963a516` |
| 被接受内部步 / 拒绝 | 120 / 0 |
| 末帧变量完全一致 | 是 |
| 末帧 `internal_step_s` / `local_error_norm_max` | 10 s / 1.1843e-3 |

同参数重跑一致的前提是同一代码、同一机器、同一 CoolProp 版本与相同初始项目；脚本 Worker 仍按既有仿真
时间语义采样，不因内部缩步改变采样时刻。
