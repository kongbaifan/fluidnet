# C1 证据：复合压降微分与约化方程

- 工作包：C1（依赖 C0）。实施日期：2026-10-23。核对基线 v0.5.0 `a986ca3`。
- 代码：`backend/fn_engine/hydraulic_plan.py` 的 `_ReducedSolve`（残差/Jacobian/冷启动）。
- 环境：Windows、Python 3.11.0、scipy 1.17.1、默认 `dense`、`series_compression=True`。

## 1. 冻结方程

一条链 `b1..bk`（遍历符号 `s_i = ±1`）共享一个质量流量未知量 `q`（kg/s，沿遍历方向为正）：

```
复合压降    F(q) = Σ_i s_i · drop_i(s_i · q)
复合斜率    F'(q) = Σ_i drop_i'(s_i · q)        # s_i·s_i = 1
链方程      p_start − p_end − F(q) = 0           # 环链：start == end ⇒ F(q) = 0
```

`drop_i` 与 `drop_i'` 直接复用 `hydraulic_derivatives.branch_drop_and_slope`（与 J2 解析 Jacobian
同源），因此同向/反向安装、不同管径/粗糙度/阻力、泵阀串联都走同一公式；泵曲线外工况仍由
`branch_drop_value` 的线性延拓定位根，再由 C2 的**原网络**校验收敛后的工作点并报原有错误（§4）。

单位/缩放与 `solver._solve_hydraulics` 完全一致：支路行除以 `PRESSURE_SCALE`，质量平衡行不缩放；
未知压力列本身是 `p/PRESSURE_SCALE`，所以 Jacobian 的压力项是 `±1`，流量项是 `−F'(q)/PS`
（`test_series_compression.py` 里用中心差分对上了解析 Jacobian，见 §3）。

## 2. 冷启动初值（本次新增，避免小网络反优化）

对**纯被动链**（成员只含 valve/pipe/resistance），用 `F(1)` 作尺度反推初值：

```
q0 = sign(Δp_est) · sqrt(|Δp_est| / |F(1)|)      Δp_est = p_est[start] − p_est[end]
```

`p_est` 固定压力取真值、其余锚点取固定压力均值；含泵或非单调情形退回 0.1（与常规路径一致）。
零流量保护（`|q0| < max(1e-6, 100·mass_tolerance)` → 0.1）保留。

实测收益（6 串联，同一网络）：冷启动 nfev **10 → 4**，warm（接受解作初值）**1**；
2 串联 nfev **12 → 5**。按大小实测的端到端 `solve_steady` 中位数（同机、7 次）：
2/4/6/8/12/16/20/30/60 串联时“压缩/未压缩”耗时比 **0.94 / 0.75 / 0.65 / 0.75 / 0.55 / 0.36 / 0.47 / 0.19 / 0.19**，
即改进后小网络也不回退（此前 2–12 串联压缩侧是 1.2–1.5× 回退；该数据保留在 C3 §5 的对比说明里）。

## 5. 方法选择与稀疏请求

约化系统同样按 `choose_hydraulic_method(options.hydraulic_method, reduced_size, reduced_nnz)` 选择：
显式 `sparse` 时用 CSR 解析 Jacobian + `tr_solver='lsmr'`；显式/auto 的 `requested_method`、
`effective_method`、`matrix_size`、`matrix_nnz`、`method_reason` 都写回 `HydraulicResult`。
实测 mesh（约化 4 未知量、9 nnz）：`requested='sparse'`、`effective='sparse'`，与未压缩 sparse 解在
3.1 门内一致（`test_sparse_request_is_honored_on_reduced_system`）。

## 7. 已知限制

- 链内复合压降每次残差是 O(m)（1000 成员 ≈ 每次残差 1000 次 `branch_drop_and_slope`），
  没有做“同质链闭式聚合”；因此 1000 串联压缩后仍有 ~96 ms，而不是常数时间。
- 交叉链（同一未知压节点连 3 条以上链）只共享该节点的 1 个未知压力，未做多链合并。
- 无压力参考的纯环/分量不压缩（交回常规路径报错）。
