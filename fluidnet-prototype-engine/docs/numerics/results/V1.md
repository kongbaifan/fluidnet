## 1. 两条候选方案

v2 **不新增 relation kind**：仍用既有 `valve`（`Δp = 1e5·(ρ/1000)·Q|Q|/Kv_eff²`，`Kv_eff = Kv·opening`），
模块在 `evaluate` 里只决定 `opening ∈ [0,1]` 或精确 `0`。因此两种方案都可只用模块关系表达：

| | (a) 光滑过渡（C∞ 二极管） | (b) 互补 / 活动集（精确零流） |
| --- | --- | --- |
| 开度 | `gate = 0.5·(1 + tanh((Δp − p_crack)/w))`，处处 > 0 | `Δp ≤ p_crack` 时 `opening = 0.0`（精确）；否则 `√(1 − p_crack/Δp)` |
| 正向开启压差 | **不存在**：`Δp = p_crack` 处已经半开 | 存在：`Δp ≤ p_crack` 精确零流 |
| 反向 | 有界但**非零**泄漏（`Kv·gate·√(|Δp|/C)`），上界见 §2 | **精确 0**（`flow == 0` 等式约束） |
| 光滑性 | 处处 C∞ | 开关点 C0、左右导数不同（如实声明） |
| 需要求解器改动 | 不需要 | 不需要（关系层活动集）；迟滞才需要外层活动集 |
| 实测表现 | 临界附近失败（§2） | 全部通过（§4–§8） |

## 2. 方案 (a) 光滑二极管的实测（选择依据）

对照模块源码在 `tests/test_check_valve_numerics.py::SMOOTH_SOURCE`（只用于验收，不发布），参数
`width_pa=500`、`p_crack=5000`、`Kv=50`。

| 检查 | 实测 | 结论 |
| --- | --- | --- |
| `Δp = 5000 Pa`（刚等于 p_crack） | `opening=0.5`、`q=1.551485286 kg/s` | 没有“开启压差”：应截止的压差点已半开 |
| `Δp = 5001 Pa` | `q=1.5547437 kg/s`、nfev=11 | 与 v2 的 `0.04388 kg/s` 相差约 35 倍 |
| `Δp = 10000 Pa` | `q=4.3882631 kg/s`、nfev=14 | 远高于 p_crack 时接近全开（v2 为 3.10297） |
| `Δp = 0 / −1 / −1000 Pa` | **收敛门失败**（`HydraulicNotConverged` 或残差超 1 Pa 门） | 极小开度（1e-7～1e-11）等价于用 `1e-9` 开度近似关断，正是计划禁止的做法 |
| 反向泄漏上界（纯函数扫描） | `width=100: 0`（tanh 下溢）；`width=500: 6.13e-10 kg/s @ −125 Pa`；`width=2000: 3.99e-3 kg/s @ −501 Pa` | “有界泄漏”确实有界，但泄漏随 `width` 增大，而缩小 `width` 又回到刚性区 |

临时探针（2026-10-23，tmp 脚本，不入库）记录的失败残差量级：`Δp=−1000 Pa` 压力残差 4.16e5 Pa、
`Δp=−1 Pa` 140.8 Pa、`Δp=0` 139.4 Pa（`xtol` 提前满足）；`Δp=1000 Pa` 能收敛但需 **31 nfev**（v2 为 2）。

**结论**：方案 (a) 无法同时满足 V0 冻结的“正向开启压差”与“反向截止”，且在阈值下方会退化成极小开度近似；
**选择方案 (b)**。全程没有用减小 dt 或放宽容差来“修复”稳态。

## 3. 方案 (b) 的等价性与连续性

`opening = √(1 − p_crack/Δp)` 代入 `valve` 律：

```
Δp = 1e5·(ρ/1000)·Q|Q|/(Kv·opening)²
   → Q = Kv·opening·√(Δp/(1e5·ρ/1000))
   → Q = Kv·√((Δp − p_crack)/(1e5·ρ/1000))
```

即“开启压差 + 阀门阻力串联”。开关点 `Δp = p_crack` 处关闭行是 `q=0`、开启支路极限也是 `q→0`，
残差连续（C0）；但关闭行不含压力、开启支路 `∂q/∂Δp → ∞`，**不承诺 C1**。

## 8. 泵旁路与并联

### 8.1 泵旁路（默认路径，真实 Worker）

`source 150 kPa → J1`，`J1 → 泵 → J2`，`J1 → 止回阀 → J2`，`J2 → source 250 kPa`；泵转速 1.0。

### 8.2 并联止回阀

两个 v2 实例 `Kv=50` 与 `Kv=30` 并联，`Δp=50 kPa`：`q1=9.8124545`、`q2=5.8874727 kg/s`
（比值 1.66667 = 50/30，相对误差 < 1e-9），`nfev=15`、`res=45`、`rpc_b=46`、`rpc_i=92`
（批量 Worker：每次残差调用一批两个实例）。`Δp=−50 kPa`：两阀均精确 0，压力/质量残差均为 0。
