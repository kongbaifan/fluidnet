## 1. 冻结结论（与 §5.1 逐条一致）

| 项 | 冻结值 / 语义 |
| --- | --- |
| 压差 | `Δp = p_in − p_out`（Pa） |
| 正向开启压差 `p_crack_pa` | 默认 `0.0`；`Δp > p_crack` 才导通 |
| 反向截止 | **精确零流**：`Δp ≤ p_crack`（含全部反向）时 `opening_ratio` 精确 `0.0` → 求解器 `flow == 0` 约束 |
| 泄漏 | **不选有界泄漏**；反向/亚开启区通过质量声明上界 **0 kg/s**（只剩 `mass_tolerance_kg_s` 容差，默认 1e-8 kg/s，不是物理泄漏参数） |
| 迟滞 | `hysteresis_pa` 默认 `0.0`（无迟滞）；`Δp ≤ 0` 恒关 |
| 光滑性 | 开关点 `Δp = p_crack` 残差 **C0 连续**（两侧 q→0），但左右导数不同；**不承诺处处光滑** |
| 旧版本 | v1 源码与契约快照保持原样、不覆写；旧项目绑定 v1 语义 |

## 2. 旧参数“容许反向流”的语义与实测

v1 参数 `cracking_pressure_pa` 表示**反向容许压差**：`0 < p_out − p_in ≤ cracking_pressure_pa` 时
阀门仍按正向开度**反向导通**；`p_out − p_in > cracking_pressure_pa` 才关断。

实测（单阀，`kv_m3_h=50`，水，v1 包 `modules/check_valve/`）：

| Δp = p_in−p_out | v1 `cracking_pressure_pa=5000` 实测 q (kg/s) | 说明 |
| ---: | ---: | --- |
| −1000 Pa | **−1.38769063** | 反向 1000 Pa < 5000 → “容许反向流” |
| −1 Pa | −0.04388296 | 同上，符号为负 |
| −4500 Pa | 不收敛 | `HydraulicNotConverged`（压力残差 4500 Pa，`gtol` 提前满足） |
| −4999 Pa | 不收敛 | `HydraulicNotConverged`（压力残差 4999 Pa） |
| −5001 Pa | 0（精确） | 反向压差超过 5000 → 关断 |
| +5001 Pa | 3.10328085 | 正向前向 |
| +5000.01 Pa | 3.10297368 | 正向前向（与 `cracking` 无关） |

两个根因（对应 §5.1）：

1. v1 的关断判据落在 `Δp = −cracking`，`Δp` 略高于该点（如 −4999 Pa）时“开启支路”的残差比
   关闭支路多出 `cracking_pressure_pa`（5000 Pa）的跳变，`least_squares` 可能停在 q≈0、
   `gtol` 提前满足 → 报不收敛。
2. 反向“容许”本身就是物理错误：止回阀不应在任何反向压差下通过。

v2 的做法：关断判据改到 `Δp = p_crack`（此处两支路 q 都 → 0，残差连续），并且无论 `p_crack`
取多少，反向都精确截止。

## 3. 独立参考（不经求解器）

`backend/fn_engine/check_valve.py` 提供的冻结参考路径：

| 函数 | 作用 |
| --- | --- |
| `is_open(Δp, p_crack, hysteresis, was_open)` | 开/关判据（`Δp ≤ 0` 恒关；`h=0` 与状态无关） |
| `required_opening(Δp, p_crack, opening_max, hysteresis, was_open)` | evaluate 应写入的 `opening_ratio`；关闭返回精确 `0.0` |
| `valve_mass_flow_kg_s(kv, opening, Δp, ρ)` | 求解器 `valve` 关系的解析流量 |
| `reference_volume_flow_m3_h` / `reference_mass_flow_kg_s` | 独立 Δp–q 曲线：`Kv·opening_max·sqrt((Δp−p_crack)/C)`，`C = 1e5·ρ/1000` |
| `reference_pressure_drop_pa(params, q)` | 参考曲线逆函数（给定流量求压降） |
| `opening_slack_pa` / `complementarity_residual` | 互补条件 λ = p_crack − Δp、λ·q 残差与自洽判据 |
| `next_open_state` | accepted 步的迟滞状态转移纯函数 |
| `smooth_*` | 方案 (a) 对照曲线与反向泄漏上界（V1 证据用） |

关键恒等式（`test_v0_reference_curve_is_the_cracked_valve_law` 逐点断言，`rel=1e-12`）：

```
opening = opening_max·sqrt(1 − p_crack/Δp)
q_vol   = Kv·opening·sqrt(Δp/C) = Kv·opening_max·sqrt((Δp − p_crack)/C)
```

即“开度反算”后的阀门律与独立物理曲线**逐点相同**，所以 v2 不用改求解器、也不用 `1e-9` 开度近似。

## 5. 与 v1 的等价性（p_crack 默认 0）

`test_v1_default_crack_zero_matches_v1`：把 v1 的 `cracking_pressure_pa=0` 与 v2 的 `p_crack_pa=0`
放在同一组 Δp 上，**流量逐位相同、`nfev` 相同**（详见 `V1.md` 表 3）。因此 v2 在默认参数下
不改变 v1 的正向行为，差异只在“旧参数非零时的反向语义”和更靠前的开关点。
