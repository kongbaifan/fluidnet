## 1. 配置字段（默认关闭，旧默认不变）

| 字段 | 类型/单位 | 默认 | 拒绝规则 |
| --- | --- | ---: | --- |
| `enabled` | bool | `False` | 关闭即走 v0.5.0 固定步长路径 |
| `mass_atol_kg` | kg | `1e-9` | 非有限/≤0 拒绝 |
| `energy_atol_j` | J | `1e-3` | 非有限/≤0 拒绝 |
| `temperature_atol_k` | K | `1e-5` | 非有限/≤0 拒绝 |
| `rtol` | 1 | `1e-6` | ≤0 或 >1 拒绝 |
| `min_internal_step_s` | s | `1e-3` | ≤0 或 >60 s 拒绝；须小于有效最大步长 |
| `max_internal_step_s` | s | `None` | `None` 表示沿用 `SolverOptions.dynamic_step_s`；显式值 ≤3600 s |
| `safety` | 1 | `0.9` | 必须 (0,1] |
| `growth_factor` | 1 | `2.0` | 必须 (1,10] |
| `shrink_factor` | 1 | `0.5` | 必须 (0,1) |

显式拒绝的契约（测试 `test_non_positive_tolerances_are_rejected`、
`test_tolerances_must_name_their_unit`、`test_minimum_step_must_be_below_maximum_step`、
`test_unsupported_execution_domains_are_rejected`）：

- 容差必须带单位后缀：`mass_atol_kg` / `energy_atol_j` / `temperature_atol_k`。写 `mass_atol`、
  `atol`、`mass_atol_j` 等会报“单位不明确”，不猜数量级。未知字段仍由 `StrictModel(extra='forbid')` 拒绝。
- 非正容差、`min_internal_step_s >= max_internal_step_s` 在 pydantic 校验阶段拒绝。
- 执行域不在 `{'thermal','refrigeration'}` 时，`ensure_supported` 抛
  `TIMESTEP_DOMAIN_UNSUPPORTED`（`SimulationSession` 与 `ThermalSession` 建会话即拒绝）。通用流体项目与
  冷库 A（`cold_store`）都已用测试确认拒绝。
- 旧项目 JSON 没有 `time_step` 字段时按关闭解释；`Project.model_validate` 与保存/恢复保留全部字段
  （`test_defaults_keep_the_old_fixed_step_mode`、`test_snapshot_keeps_every_time_step_setting`）。

## 2. 快照与兼容

`time_step` 是 `SolverOptions` 的嵌套严格模型，随 `Project` 进入项目保存、工况复制和运行请求；
`Project.model_dump(mode='json')` → `Project.model_validate` 往返后逐字段相等。`RunFrame.metrics` 只新增
数值键（见 §4），旧读取路径不变；关闭时数值结果与 v0.5.0 逐变量、逐计数一致（A2 证据）。

## 3. 默认参数的确定

默认值在 A1 理想热模型（解析解）上扫描后取“中等容差”：`rtol=1e-6`、温度 atol `1e-5 K`、能量 atol
`1e-3 J`、质量 atol `1e-9 kg`。实测（A1 证据表）：`rtol 1e-4` 端值误差 0.090 K / 11 步，
`rtol 1e-6` 为 0.013 K / 74 步，`rtol 1e-8` 为 0.0013 K / 701 步；默认档在精度和成本之间，且缩紧容差
误差单调下降。冷库 B 在 10 s 控制采样下默认档只有离散切换时刻触发少量拒绝（A3 证据）。

## 4. 冻结的指标键（A4 报告直接使用）

`timestep_adaptive`、`internal_step_s`、`internal_steps`、`internal_rejections`、`solver_retries`、
`boundary_truncations`、`local_error_norm_max`、`internal_steps_total`、`internal_rejections_total`、
`accepted_step_min_s`、`accepted_step_max_s`。语义见 `timestep.py` 模块 docstring；`local_error_norm_max`
只描述 **局部** 时间离散误差估计，报告不得称为全程误差或模型准确度保证。

## 5. 事务约定（冻结，A1/A2/A3 共同遵守）

- 整步、两个半步、拒绝重试都不提交 PID、脚本、设备累计量、Worker 状态或求解缓存；只有
  `error_norm <= 1` 才按细步路径提交。
- 输出时刻、控制采样、日程、融霜与启停边界截断内部步长；边界截断的细小步与因误差触底最小步长
  分开诊断（`boundary_truncations` 与 `TIME_STEP_BOUNDARY_EXCEEDED` / `TIME_STEP_MIN_EXCEEDED`）。
- 最小步长仍不满足误差时停止并保留已接受历史，不静默放宽 atol/rtol。
- 能量状态相对冻结参考态中心化；容器派生压力另做整步/细步差值检查。
