# 冷水机组与真实水盘管联算验收

日期：2026-10-29；基线 `5c68d92`，分支 `claude/chiller-air-loop`。沿用已有设备纯函数，补齐编译、混合回路求解、动态接受、目录/报告、界面和完整示例。

## 实现

- `air_liquid.py` 在同一候选网络状态上计算盘管和机组两侧，水侧用各自工质的比焓和质量流量，空气侧用干空气焓与含湿量。水力压损仅对空气支路乘湿空气总质量因子。
- 编译器逐回路校验工质、双侧通路和独立性；液体节点不参与湿空气物性、速度和水分参考校验。普通水系统也能使用冷水机组。
- 机组最终工作点执行运行包络检查；风水联算不为闭式水回路添加温度钉扎或补偿热量。
- 盘管凝水/冷量、机组制冷量/耗电量进入既有接受子步事务；历史冻结目录保留空气与液体的字段差异。
- 新增 `chiller-air-loop` 规范/API/界面示例，分空气/液体表显示端口，状态图仅画空气点。新设备可从模块库插入，双侧端口在画布上分开定位。
