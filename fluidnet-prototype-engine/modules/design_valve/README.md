# 流量压差选型阀

`design_valve` v1，普通单相液体；运行复用线性Kv阀关系，累计质量按接受步提交。

在设备参数面板点击“设备选型”，输入目标体积流量、压差、进口绝压、温度与开度；设计函数按入口密度计算 `Kv = Q[m³/h] / opening × sqrt((ρ/1000)/(Δp/1e5))`，出口用等焓物性检查液相。全部设计输入均声明于模块合同，内部规范单位Pa/K/m³/s；界面显示kPa/°C/m³/h。

预览后可保存为型号并填入设备草稿；“确认应用”后才改变实例参数。设计条件不创建压力边界、不强制运行流量；厂家尺寸、气蚀、闪蒸、噪声和阀权度尚未校核。开度为0时允许运行关阀，设计选型则明确拒绝。
