# 异径管（渐缩／渐扩）

从模块库“暖通基础设备”插入。入口和出口内径按 mm 编辑，过渡长度决定锥形过渡全角；过渡形式可填 `gradual`（渐变）或 `sudden`（突变）。反向流自动交换收缩和扩张计算，端口名称不变。

这是常用工程近似的**不可逆局部损失**模型。K 始终以较小管径的流速为基准，`Δp = K·ρ·v_small·|v_small|/2`；不包含动压向静压恢复、沿程摩擦、偏心影响、汽蚀或两相流。实际产品应使用手册／厂家数据校核修正倍率；型号默认值不是实测标定。

设 `β = D_small/D_large`、`θ = 2 atan((D_large−D_small)/(2L))` 为全角：

| 流向 | θ ≤ 45° | θ > 45°（突变取 180°） |
| --- | --- | --- |
| 收缩 | `K = 0.8 sin(θ/2)(1−β²)` | `K = 0.5 sqrt(sin(θ/2))(1−β²)` |
| 扩张 | `K = 2.6 sin(θ/2)(1−β²)²` | `K = (1−β²)²` |

关系采用常见锥形变径局部损失近似，突扩退化为 Borda–Carnot 关系，突缩为工程经验近似；45° 切换属于分段关联式，不表示厂家曲线在该点连续。两端等径时局部损失为零，需要网络中其他阻力或约束确定流量。

默认是入口 100 mm、出口 50 mm、过渡长度 150 mm、修正倍率 1。输出两端有符号流速、实际 K、面积比、全角、局部压降和接受后累计通过质量。已有 `pipe_fitting` 的固定 K 模块保持其原版本，两个模块分别提供。

新模块复用 `net.resistance`，可进入普通单相网络和风水联算中的液体支路；无独立物理储量，不调用新自定义压降协议。静态几何不允许运行中修改。
