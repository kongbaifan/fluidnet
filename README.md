# FluidNet Studio

本地运行的流体网络计算工作台，当前版本 **0.2.0**，面向液态水与暖通水系统。通过拖放元件、连接端口和配置工况，计算管网压力、流量与温度，并记录设备慢动态和控制过程。

v0.2 新增单层组合设备、内部画布、可配置的端口与参数接口、带版本的型号库和独立验证台。组合内仍保留完整管网，已有项目实例独立保存，通过差异预览手动应用型号版本。

## 启动 Windows 免安装版

1. 完整解压 `FluidNetStudio-Windows-x64-0.2.0.zip` 到有写入权限的文件夹。
2. 双击其中的 `FluidNetStudio.exe`，浏览器会打开 <http://127.0.0.1:8765>。
3. 保持服务窗口开启。用完后在服务窗口按 `Ctrl+C` 停止服务。

免安装版已包含 Python、计算依赖和网页资源，无需安装 Python 或 Node.js。`_internal` 目录必须与可执行文件一起保留。启动后无需联网即可计算。

如果默认端口被占用，在解压目录打开 PowerShell，使用另一个端口：

```powershell
.\FluidNetStudio.exe serve --port 8768 --open
```

项目、版本、运行记录和型号库保存在程序旁的 `workspace` 文件夹。备份前先停止服务，再复制整个 `workspace`。浏览器中的未保存草稿应先通过“保存项目”写入工作区。

从 v0.1 升级时，先保存项目并停止旧服务，再将旧 `workspace` **复制**到新版程序旁；也可用 `.\FluidNetStudio.exe serve --workspace "D:\FluidNetData" --open` 指定独立数据目录。首次打开旧工作区时会在 `workspace/backups/` 自动备份 SQLite 数据库，再升级型号库。有效的 v0.1 项目和旧型号可继续读取，旧项目版本及运行快照保持原存档。不要让两个版本同时使用同一工作区；回退时使用升级前保留的副本。

## 完成第一次计算

1. 点击左下角“打开示例项目”，选择“泵阀并联管网”。载入示例会生成可编辑副本。
2. 点击“计算”，等待状态栏显示“已完成”。画布可切换流量、压力和温度显示。
3. 选中“B 路调节阀”，修改开度，再次计算，观察两条支路的流量变化。
4. 在“运行结果”中勾选要记录的变量；下次运行后可查看曲线，导出 JSON、CSV 或 HTML 报告。
5. 点击顶部“保存项目”。运行结果会自动记录，项目编辑需要单独保存。

新建模型时，点击顶部项目名称 → “新建项目”，从左侧添加或拖入元件，拖动端口建立连接。一个端口只连接一条通路，需要分支时使用“连接节点”。运行前可点击“检查模型”定位缺少边界、端口未连接或参数错误。

“动态运行”支持暂停、继续、单步和停止。首次点击“单步推进”会初始化并停在 `0 s`，再次点击才前进一个步长。带绿点的参数可以在运行期间调节。

详细说明见 [使用指南](docs/USER_GUIDE.md)。

## 组合设备与型号复用

1. 在同一画布中用 `Ctrl+单击` 或框选选择元件，点击“封装选中元件”。设置名称和对外参数后，组合显示为一个设备。
2. 双击组合进入内部画布，可添加元件、连线和修改参数；通过顶部“主画布”返回。主画布中的外部连接映射到真实内部端口。
3. 在组合属性中点击“保存到型号库”，编辑参数与接口，并在“独立验证”页使用测试边界做稳态或慢动态验证。验证有独立的运行记录。
4. 在“型号管理与验证”中保存新版本、导入/导出 JSON 或插入副本。已有实例不会随型号更新；选中实例后点击“应用到选中实例”，检查差异，再点击“应用此版本”。

附带“泵阀组合”“双侧换热机组”“水箱调节单元”三套型号。它们展示接口、独立水回路与水箱慢动态的配置方式。组合仅支持单层，设备行为由现有元件参数和内部管网定义。

## 当前计算范围

- 18 类元件：压力/流量边界、用水需求、连接节点、管道、局部阻力、泵阀、热设备、水箱、测量与控制。
- 单相纯液态水，物性使用 CoolProp 的 IF97 后端；支持独立介质配置和换热器两侧回路。
- 稳态水力和热力耦合；水箱质量/焓、管内热输运与控制器的慢动态。
- 6 套示例、3 套组合型号，项目版本、工况对比、单层组合与型号版本管理、最多 16 张画布。
- 每个项目最多 1000 个元件，同时记录最多 64 条曲线；运行任务默认最多 2 个进程并行。

气体、蒸汽、制冷剂及混合物仍是预留接口。当前版本不计算水锤、声学瞬态或相变；进入非液态区会报告诊断。1000 个元件是模型数量上限，不代表已完成相应规模的性能验证。

## 从源码运行

已验证环境为 Windows x64、Python 3.11，以及 Node.js 20.19+ 或 22.12+。在项目根目录执行：

```powershell
python -m pip install --target .runtime/python -r requirements.lock.txt
npm ci
npm run build
npm run preview -- --open
```

Python 依赖放在项目内的 `.runtime/python`，启动脚本会自动加载它们。前后端联合开发使用 `npm run dev`，访问 <http://127.0.0.1:5173>。

| 命令 | 用途 |
| --- | --- |
| `npm run check` | Python 语法和前端 TypeScript 检查 |
| `npm test` | 后端测试、前端构建及浏览器测试 |
| `npm test -- -q` | 仅运行后端测试 |
| `npm test -- --e2e` | 重新构建网页并运行浏览器测试 |
| `npm test -- --e2e --grep "a new project"` | 运行指定浏览器测试 |
| `npm run build -- --portable` | 生成 Windows x64 免安装目录和 ZIP |
| `npm run smoke:portable` | 在隔离的子进程环境中验证已构建的程序 |

浏览器测试默认使用本机 Microsoft Edge。测试数据写入 `.cache/e2e-workspace`，打包自检数据写入 `.cache/portable-smoke`，不会使用正式 `workspace`。便携目录位于 `dist/portable/0.2.0/FluidNetStudio/`，ZIP 位于 `dist/FluidNetStudio-Windows-x64-0.2.0.zip`。如果该版本目录已有用户 `workspace`，构建会另选带时间戳的目录。ZIP 旁的 `.sha256` 文件用于核对完整性；包内 `build-info.json` 记录版本与依赖。

架构、接口和后续开发入口见 [开发说明](docs/DEVELOPMENT.md)。
